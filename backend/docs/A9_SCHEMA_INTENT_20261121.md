# A9来源权限投影到输出Schema

仅修改新后端，复用已有来源校验器与意图权限表，不新增几何生成器，不放宽来源、形态或平滑验收。

## 实现

`_request_construction_schema`接收当前解释器已经生成的只读来源索引，首次建模及已有部件修复回调使用同一份请求Schema。

`JunctionConstraint`改为按授权意图组成`oneOf`：每个分支同时约束intent、对应连续性和来源引用枚举。平滑允许G1/C1；有明确来源的尖点、折角允许C0。来源引用为必填非空列表，不能将另一意图的来源跨用。没有任何授权意图时，该可选列表不得包含任何接缝声明，空列表或省略仍可使用。

执行器仍验证实际引用及几何。请求Schema是提供给模型的输出契约，不是模型一定遵守的保证，也不替代运行时校验。没有把图形名称自动变成尖点授权，没有自动改动模型几何。

增加回归覆盖三类意图、来源列表隔离、无授权、不受后端反馈伪造来源影响、请求之间不污染及首次实际回调收到受限Schema。默认CAD回归**832项通过**：`.local-dev/test-b7bbim7h/result.json`。
