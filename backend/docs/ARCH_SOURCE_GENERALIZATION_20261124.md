# 组合边界来源覆盖与表示一致性（2026-11-24）

本轮继续修复已存在测量能力与来源覆盖之间的断点，范围为水平半圆拱门。没有新增生成器、按语料编号分支或将未知要求直接设为通过。胶囊、开放折线和任意组合要求的完整覆盖尚未完成。

## 根因与变化

`verify_native_semicircular_arch`和`verify_semicircular_arch`已经能够从实际CAD识别半圆顶、等高竖墙、水平底边和唯一闭合边界。旧来源适配器却要求用户同时写出宽、高、半径、墙高四个数值，且形状名必须匹配“半圆拱门”。这会使“总宽、总高；顶部为半圆”的等价需求无法获得完整覆盖。

现在继续使用原测量器，以总宽和总高为必要尺寸，核对半径=宽/2、直墙高=总高−半径所对应的实测边界。原文额外给出半径、直径、墙高时仍分别检查，矛盾数值不能被派生关系覆盖。底边起点绑定到实际边界左下端，使用原文坐标单位换算后核验。适配器不读取模型断言或据此生成新坐标。

来源规则将“上半圆、等高竖墙、水平底边、无内部线”等要求关联到已经通过的拱门几何身份检查，并复用完整预览操作意图解析。剩余的旋转、标注、额外部件、否定或未支持词句仍保持partial，不忽略。规则不覆盖所有自然语言同义表达，不声称已成为任意文本解析器。

## 表示与精度

离散拱门测量器此前只检查最大弦偏差不超过半径的0.5%，可能容许数毫米偏差。现增加共享0.5毫米绝对上限，同时保留原相对上限，防止粗采样因为曲线半径较大而获得形状通过。生成器沿用上一轮0.2毫米采样预算；无法达到预算仍拒绝。

## 验证

新增`test_arch_source_generalization.py`包含三组不同尺寸/偏移位置、两种图元表示，以及另一种措辞和厘米单位；通过生产解释器的完整验收，并对六种组合执行正式持久化和候选状态检查。各组还验证错误位置、错误总高、附加圆、旋转、标注与否定要求不会获得完整覆盖。另有粗采样负向检查。

包含既有C3/C6/C33及独立闭合边界oracle的定向检查：25项通过，证据`.local-dev/arch-final-r7_i68zx`。测试互有覆盖，不能相加为独立案例数。

完整回归首次发现旧正向夹具以64段逼近半径2米的半圆，实际弦偏差约0.60毫米，原相对阈值允许它通过。本轮按0.2毫米弦误差预算计算该正向夹具的采样数，未改生产验收阈值。另一个负向夹具明确保留全部角点、闭合性和顶点位置，只让弦偏差超过0.5毫米，验证其被拒绝。相关12项检查通过，证据`.local-dev/arch-precision-final-znmgd4w2`。

模型回调在上述测试中使用固定计划，目的仅为隔离后端验收与保存环节。未调用真实DeepSeek、未重算48试次或70条成绩，未上传GitHub，也未修改旧目录。真实模型规划稳定性需要后续冻结源码的独立复测。
