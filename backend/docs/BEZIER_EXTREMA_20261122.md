# 二次、三次Bezier解析极值候选测量

本轮新增离线测量`evaluations/bezier_extrema_v1.py`，版本`cad.bezier-extrema.v1`。只求导数零点与端点候选，复用已有`cad_construction._bezier_point`计算坐标，没有复制点求值器，没有生成或修改曲线，也未改生产验收。

## 测量范围

对3或4个控制点的Bezier，按相邻控制点差构造一阶或二阶导数多项式，分别求x/y轴在[0,1]内的根，与区间端点合并后求坐标范围。使用稳定二次求根形式，检查归一化导数残差。整轴恒定与孤立驻点分别记录；导数存在重根并不自动意味着它是极小值，仍比较全部候选。

判别式接近数值不确定的负值或残差不可靠时返回未验证，而不是偷偷丢掉根。结果是浮点解析候选计算，不是区间算术认证。`formal_candidate_accepted=false`，未应用布局、单位换算或后续变换；不能直接把源控制点坐标当成最终交付毫米坐标。

尚不支持任意参数表达式、B样条、混合复合路径整体极值，也不能仅凭某段y恒定就断定它位于整体最低位置。

## 验证

相关测试**15项通过**：`.local-dev/bezier-extrema-final-e6ukexqw`。涵盖：

- 极小值在t=0.3、普通采样网格之间的二次曲线。
- 同时有t=0.2、0.8两个驻点的三次曲线。
- 平轴、退化曲线、近线性曲线、端点根及重根。
- 不同单位数值尺度和平移下的位置关系。
- 输入不修改，未支持次数拒绝；与原曲线证据关联测试一并验证。

参考二次曲线y=(t-0.3)²+2，解析最低值为2。12组采样数量/相位对照分别产生不同的离散最低点，而解析候选来自同一组控制点，不依赖这些采样相位。这不是通过插入新点修改交付折线。

同一工具读取历史计划中的8段Bezier，记录源坐标系的候选极值，未将其换算成正式验收。报告：`.local-dev/BEZIER_EXTREMA_20261122.json`，含实现哈希、对照记录及原段编号。

没有调用DeepSeek、修改原模型计划或更新70项通过率，也没有声称新的全量回归结果。

## 下一步

接下来应把源曲线极值与已有执行布局变换正确关联，限定在转换关系可追溯的计划中，核验整体最低集合是孤立点还是实际平段。混合路径、未审计变换及数值不确定情况继续返回未确定，不能仅扩大容差放行，也不能把一段Bezier的结论推广到整幅图。
