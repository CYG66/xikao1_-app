# Bezier极值与执行布局关联

本轮新增离线测量`cad.bezier-layout-minimum.v1`，未修改生产应用、采样器、正式规则或旧评分，未调用DeepSeek。复用既有执行器和上一轮Bezier导数根测量，不生成或替换任何CAD几何。

## 支持范围与方法

限定单个无额外几何约束、由二次/三次Bezier段组成的闭合复合路径；支持无布局或一个绑定该输出的宽高/中心布局。多步骤、混合线段/圆弧/样条、旋转重复、相对其他对象定位及参数表达式均暂返回未验证。

对同一计划执行两次：一次保留布局，一次去掉布局及只用于结果检验的断言。使用实际采样边界的前后包围框恢复正比例缩放和平移，再逐点核对同一映射；残差超过1e-6毫米、采样数量改变或变换不可支持时拒绝推断。此处恢复的是实际执行布局映射，而非用解析极值重新拟合尺寸，因此不改变实际交付。

把各Bezier段在源计划单位下的解析候选映射到最终毫米坐标，比较整体最低高度。y恒定且位于整体最低处、具有非零x跨度的段记为最低平区间；其他最低候选汇总去重，区分一个或多个孤立最低点。最低点分类不是完整形态验收，不能单独放行爱心。

数值比较阈值单独记录，结果仍属于浮点解析候选、不是区间算术认证。该阈值用于比较极值数值，不替代用户尺寸容差或曲线采样误差。

## 验证

相关测试**20项通过**：`.local-dev/bezier-layout-final-4239gabi`。包括：

- 已知极小值位于采样网格之间，经非等比宽高缩放及中心平移后仍为孤立最低点；证明解析最低高度可略低于交付折线最低点。
- 米、毫米计划得到对应的毫米映射。
- 真正水平的Bezier底段经布局后仍是最低区间，测试区间为[4000,8000]毫米，最低高度5500毫米。
- 原输入不被修改，逐点映射残差通过检查。
- 混合路径及多步骤不被误当成可证明的单源Bezier轮廓。

历史回放：响应3是参数曲线，按限定范围返回未验证；响应5和7可关联原Bezier及布局，均测得孤立最低点。二者原正式结果仍失败，特别是响应7仍无中央凹陷。孤立底点不能把一个上部错误的轮廓变成合格爱心。

独立结果`.local-dev/BEZIER_LAYOUT_MINIMUM_20261122.json`保存源极值候选、实际布局矩阵、残差、最低点及交付采样最低高度差、输入与实现哈希。旧报告和原模型计划保留。
