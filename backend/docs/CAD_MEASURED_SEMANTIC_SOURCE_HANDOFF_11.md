## 实现边界

`cad_semantic_source_coverage.verify_measured_semantic_coverage` 复用既有语义测量结果，只覆盖已有的正多边形/同心孔、嵌套正方形契约。它核对原文各次出现的尺寸、形状数量词及受支持的中心描述；附加位置、旋转、面积、标注、额外对象、冲突尺寸等未被完整消费时继续 partial。不会仅凭 semantic_acceptance.status=passed 就提升整段需求。

`cad_source_acceptance.verify_final_source_contract` 直接测量被绑定的闭合直边图元：等边轮廓可测边长；只有各角顶点都位于测得包围圆圆周的 0.5mm 误差范围内时才给出外接圆半径，否则仍未验证。没有清空最终标量验收中的未知要求来换取通过。

正多边形边长使用通用关系 `R = s / (2*sin(pi/n))`。测试覆盖 n=3、4、5、6、8，不含按案例编号选择逻辑、生成坐标或提供新模板。阵列、蜂窝等多单元请求继续使用原有重复结构验收。

几何验收沿用已有 0.5mm 尺寸容差与角度容差。新增来源消费层对重述/冲突字段保持保守；未支持的复杂修订语义不会自动消解。

解释器保留支持契约下的未消费原文诊断。失败汇总脚本新增 execution_failure_details 和 failed_checks，保存执行失败的具体字段、期望值、实测值及定位信息。
