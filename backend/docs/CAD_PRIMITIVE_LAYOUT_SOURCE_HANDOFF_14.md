## 支持范围

新增 `cad_primitive_layout_acceptance.verify_primitive_layout`，只读取原文和实际图元，不读取模型计划、标签或断言作为验收依据。

当前完整来源覆盖支持：

- 明确声明一个圆和一个矩形的双图元清单，具有各自明确坐标和尺寸；支持清单顺序互换、圆/圆形与矩形/长方形名称、和/与连接，以及部件内部坐标和尺寸字段顺序变化。
- 明确圆环及内外半径，按实际两圆包含、同心、半径及可选的“均圆心”坐标测量。

两类描述都要求原文全部消费、各次字段重述一致。单位冲突、额外图元、旋转、标注、面积等未支持要求不能因此获得完整覆盖；复杂修订语义仍保守处理。缺少坐标单位时不猜测非零坐标尺度。

`cad_relation_acceptance` 在只有一个相应基础名称时使用圆/圆形、矩形/长方形的明确别名。若两个名称都已被声明为不同对象，不自动合并。新增“在/位于…正上方、正下方、正左方/侧、正右方/侧”：既测量边界方向，也要求垂直于方位的中心轴对齐。沿用已有0.5mm容差，不添加任意间距。

`cad_requirement_contract` 将明确的“内圆/外圆半径或直径”记为部件事实，不将其错误归给整体圆环；原文证据位置仍指向原始字符串。`verify_final_source_contract` 通过实际包含关系验证这些作用域，无法唯一确认时保留未知要求，不从半径值或标签反猜对象。
