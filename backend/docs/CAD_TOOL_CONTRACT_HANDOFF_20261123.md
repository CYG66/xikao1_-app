## 共同引用契约

`cad_plan_references.plan_reference_catalog`供计划校验、解释器引用归一化及执行绑定共同使用：

- `output_ref`：精确步骤输出，不按显示名称猜测。
- `object:<semantic.object_id>`：显式、唯一且实际保留该身份的构造部件。
- `assembly:<semantic.assembly_id>`：该整体下保留此归属的所有部件，物理ID去重，不合并或删减几何。
- 阵列、模板展开会产生实例身份，因此引用其集合仍使用`output_ref`，不将步骤semantic种子假冒为实例对象。
- 同名不同含义、重复对象身份、未知引用均不会任取一个解释；复制的`source_ref`仍只能引用此前步骤的精确输出。

`symbol_table`保留原有“一步一输出”的含义，避免既有面积归一化或版本代码把别名当成额外对象。新`reference_table`是执行结果中的派生查找表；增加别名不增加逻辑对象或持久化几何。

## 工具输入范围

|工具|接受的引用集合|测量或变更语义|
|---|---|---|
|entity_count|单个或多个图元；可省略选全部|物理图元数，不是顶点或边数|
|bounds_size|单个或多个图元；可省略选全部|集合的轴对齐外包框；plan.units|
|closed|原先支持的各自闭合图元，或组成唯一闭合边界的开放线段/圆弧组合|不补边、不替换CAD；并不证明原文尺寸、对象数量或完整业务交付|
|radial_pattern|一条闭合多段线|不把多个圆或多个部件视为径向凸瓣|
|area|各自闭合的原生图元|面积之和；不计算开放线弧组合面积或布尔并集|
|center_distance断言|两个非空图元集合|集合外包框中心间距|
|既有几何约束|每端恰含一个物理图元|保留各类约束既有语义；不同别名指向同一图元时拒绝自引用|
|center_distance约束|每端一个图元|圆/圆弧/椭圆使用固有center，其余用坐标外包框中心；与同名断言的集合中心定义不同，已在Schema和提示中显式说明|
|free_outline_layout可写目标|唯一闭合多段线|维持原有适用范围和采样误差约束|
|free_outline_layout只读参考|单图元或整体集合|使用整体外包框；拒绝与目标共享实际图元，以及尚未完成布局的依赖|

构造closed复用`assemble_closed_boundary`。该函数新增模糊端点簇、非零bulge、零扫角和退化边拒绝；圆弧测量采用独立于预览分辨率的采样，弦误差上限0.05毫米，单弧最多20000段。端点容差为0.5毫米，仅用于只读边界测量，不将容差吸附后的点写回CAD。保留原有全选图元各自闭合时的语义，不将多个闭合对象自动宣称为一个物理边界。

## 单一关系：端点重合

复用`ConstructionConstraint`、builtin求解器的平移操作及最终残差复核，新增：

```json
{
  "kind": "endpoint_coincident",
  "constraint_id": "join",
  "target_ref": "object:moving",
  "reference_ref": "object:fixed",
  "target_endpoint": "start",
  "reference_endpoint": "end",
  "tolerance": 0.001
}
```

目标端点与参考端点均显式选start/end。求解只平移一个目标图元，不旋转、不改长度或半径，不猜测相切关系。支持直线、开放多段线、非整圆圆弧。圆、闭合多段线、零扫角或整圆弧、未支持的样条端点均不会被猜作有效端点。

本轮仅支持builtin；显式选择原生后端时拒绝，不冒充原生求解或隐式回退。每次求解后按最终CAD计算端点距离，单位毫米，容差由plan.units换算。后续约束破坏前面关系时，沿用最终全量残差检查拒绝输出；不会将顺序求解失败声称为数学不可解。

共享点仍优先用于从一开始就确定的共同坐标；此约束不替代它。目标平移后若违背用户固定坐标或其他要求，仍须由独立来源验收拒绝，不能仅凭模型约束通过就正式保存。
