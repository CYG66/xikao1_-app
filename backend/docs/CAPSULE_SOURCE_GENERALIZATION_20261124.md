# 胶囊闭合轮廓、局部尺寸与交付衔接（2026-11-24）

本轮补充胶囊轮廓的只读来源验收，不新增生成器，不使用语料编号分支。仍由原有构造工具生成CAD，现有解释器和正式保存门禁决定是否交付。

## 已有能力与缺口

既有复合路径工具能检查接缝连续性，`assemble_closed_boundary`能从原生图元或离散路径检查唯一闭合边界，但未有覆盖胶囊整体形状、尺寸、位置和朝向的独立来源证明。此前局部轴尺寸还可能被通用世界外包框检查误用。

## 实测方法

`measure_capsule`复用已有闭合边界组装器，检查缺口、重复边、额外部件等问题；从实际边界的最小旋转外框测得长短轴和中心。以实际长短轴推得中轴线段，检查边界到中轴线段的距离是否恒为短轴半径，并检查边的内部采样点与凸性。只产生测量事实，不生成或修改CAD。

该几何身份在共享0.5毫米位置容差内验证胶囊轮廓，包括半圆端部及直边的近似相切连接。它不是对所有离散线段严格G1连续的解析证明；离散表示按位置精度预算判定，不能把“通过”描述为零误差精确相切。

`verify_capsule_source`逐项核对原文总长、总高、可选显式半径、中心与长轴朝向，保留原文和实测证据。轴向按180度周期比较，因为无方向标记的胶囊半转后是同一几何。角度容差0.01度。未知附加要求保留partial，未指定朝向时不自行发明约定；当前接受水平声明或显式长轴角度。

## 局部坐标保护

引入共用的局部轴尺寸识别：仅从真实来源文本读取，后端试算反馈不能改变来源坐标系。

- 局部轴尺寸不进入通用世界外包框自由缩放。
- 胶囊来源被完整识别且实测通过后，最终来源验收直接采用该完整测量证明。
- 对尚不能完整解释的局部轴要求，通用宽高检查保留未知项，不以世界外包框宽高代替它。没有跳过要求或强制标为complete。
- 只有胶囊整句全部被支持并验证才形成完整覆盖，随后走原有正式交付路径。

## 验证与限制
