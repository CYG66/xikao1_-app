# 曲线原始信息与极值能力核查

本轮未修改生产应用、采样器、生成器或验收规则，没有调用DeepSeek。新增只读评估适配器`evaluations/curve_evidence_inventory.py`，关联现有执行证据，而非另写曲线实现。

## 已有能力及边界

| 能力 | 现有代码 | 核实结果 |
| --- | --- | --- |
| 保存原构造计划 | `cad_construction.execute_construction_plan` | 返回验证后的plan，原参数式/控制点未因交付为多段线而丢失 |
| 对象来源绑定 | 同上symbol_table、step_id、output_ref | 可以将实际几何ID绑定回明确源步骤，不能按外观猜测 |
| 安全参数式求值 | `cad_parametric.expression` | 可复用既有白名单求值器，不需要执行模型代码 |
| 参数曲线自适应采样 | `cad_parametric.sample_curve` | 有预算及观测误差；文档明确不保证任意解析函数的全局误差 |
| Bezier/B样条点求值 | `cad_construction._bezier_point`、`_bspline_point` | 已有原曲线求值实现，不应再复制一套 |
| 复合曲线接缝切向 | `_segment_derivative`、`_composite_continuity` | 已测接缝，但不是整段曲线的全局极值证明 |
| 复合曲线采样偏差 | `_maximum_composite_sampling_error` | 在既有区间内做有限探测，不能当作任意曲线严格极值证据 |
| 布局缩放后的误差 | `_apply_free_outline_layout` | 质量记录有post_layout_sampling_error_bound，数值仍按plan.units，应显式换成毫米 |
| 数值优化 | `cad_parametric.verify_polar_requirements` | 已使用SciPy最小化测量特定螺线段距离；不等于已有任意参数曲线的全局极值求解器 |

在本轮审阅模块及相关搜索中，没有发现可直接复用的通用原曲线全局极值证明链。不能将原生圆/椭圆的已知解析性质、对当前IR计算的包围框，与任意参数曲线原表达式的极值混为一谈。

## 实际证据关联

适配器只读取执行结果，保留源步骤和布局信息、几何ID、质量字段及原单位，使用已有单位工具换算毫米。缺少质量报告返回未知，不能当成零误差；缺失或含糊的对象绑定返回未验证。

两份历史计划：

- 响应3能恢复原曲线，已有误差报告换算约0.4837316毫米。
- 响应5能恢复原曲线，已有误差报告换算约1.897898毫米。

这些都是现有有限探测得到的报告值，不是严格全局上界。字段即使叫bound，也不自动升级为数学保证。布局变换仍需按原计划追踪，不能直接拿原表达式坐标冒充变换后的交付坐标；多步骤变换尚未完整审计。

圆滑U形合成负例的来源是明确的`add_polyline`，应按声明的分段直线边界理解，不得为它假设一条隐藏圆滑曲线而豁免平底。

对采样曲线统一输出`status=unverified`、`extremum_verified=false`，保留下一步使用原求值器的线索，没有自动通过、扩大容差或修图。

## 下一步

现有原曲线求值、采样、接缝测量和来源绑定可以复用，缺的是从这些证据得到可靠局部极值的流程。下一步应先限定可证明的原表示范围，例如已有Bezier控制点对应的解析导数；对任意参数式或误差不足的结果仍保留“未确定”，需要精测而不是自动放行。不得重复实现现有求值器、另建形状生成器，或把有限采样估计包装成全局证明。
