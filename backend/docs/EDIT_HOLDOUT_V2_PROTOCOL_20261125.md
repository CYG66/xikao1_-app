# 新编辑留出及歧义验收v2

先冻结生产app，再编写F1/F2新名称、位置、尺寸、布局与方向需求。每条两次，共四个本轮生成基图；基图正式交付且独立0.45毫米全图oracle通过才开展后续检查。冻结期间不修源码、原句或评分，不注入图形/模型计划。

每个基图复制同一真实父版本及CAD文件到两个独立存储分支，分别发出明确编辑和未指定哪个圆的歧义请求；独立conversation、空history、明确project/variant，无对象ID或选区，避免歧义请求污染明确编辑。两分支各一次聊天调用，不额外补参/确认。新名称F2是能力边界探测，不能因不通过删掉或改写。

编辑要求新正式候选、预览、响应与保存一致、父版本不变、无新增项目、独立全图oracle符合预期。歧义v2要求clarification_required严格为true、无返回候选/待确认动作/提交工具结果，所有项目的源原文与完整候选集合前后完全不变。关键词不计入v2，旧规则只作并列信号，旧批原分数不改写。v2规则变化不得算作后端能力提升。

原旧批缺少完整分支全仓前后快照，不能伪造这些证据重新加分；只报告已有结构化澄清的诊断。v2用独立合成正反例自检，包括新项目、候选、几何、来源及返回/提交副作用。

deepseek-flash，总96请求、估算1美元预算；基图沿既有两聊天回合/12请求限制。记录源码/冻结/执行副本、协议/控制器/oracle摘要、原始API与账本；结束核对唯一性和用量。只做已有能力族的开发者内部测试，不代表第三方盲测、任意名称或CAD编辑总体通过率。
