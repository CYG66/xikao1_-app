# 爱心验收候选v2：补充底部收敛

本轮只增加评估侧规则和验证，未修改生产应用或正式验收，未调用DeepSeek。v1、旧规则与原成绩保留。

## 规则变化

新增`cad.lower-taper-relation.v1`，测量最低边界是否集中于外包框中央、是否有可分辨的平底，以及低位横截面是否包含中央并向上展开。候选`cad.heart-acceptance-candidate.v2`在v1全部检查通过后，额外要求该局部关系成立，不能只凭底部中央出现采样点放行。

测量采用最低点及全高2%、5%、10%、20%处的横截面，0.5毫米容差。相接的共线截面片段按容差合并，防止同一平底加密采样后被误当成多个不连通区域。新旧几何哈希必须一致，不能为满足规则修图。

这些截面位置和容差仍是候选规则的经验测量设置，不是用户给出的参数，不能声称是通用数学定义。对极粗采样、接近容差的窄平底、极浅底部斜率等情形还需扩大验证。

v2复用v1的来源、明确凹口要求不支持分支、形态、平滑、对称、尺寸、位置、断言及置信度检查。v1结果单独保留；底部检查失败时，v2状态和验收摘要都明确失败，不沿用v1的通过摘要。所有输出仍标记`formal_candidate_accepted=false`，不提交候选。

## 验证结果

相关测试**44项通过**，`.local-dev/lower-taper-v2-check-27z8yhu_`。包括：

- 两份历史浅凹口计划继续通过v2，旧规则仍失败，实际几何保持不变。
- 两种采样密度的圆滑U形在v1误通过、在v2因宽平底拒绝。
- 同一三角收敛边界与平底边界按1、5、20段共线加密，关系判定保持一致。
- 圆滑圆底在32、64、128个采样点下能测得局部收敛关系，但局部结果不能作为完整爱心验收。
- 既有中央凸起、未知来源、显式凹口要求保护及v1反例测试保留。

最终离线对照报告`.local-dev/HEART_CANDIDATE_V2_20261122.json`包含3份历史计划和9个合成负例：响应3、5在v1/v2通过；最终响应7仍拒绝；9个负例在v2全部拒绝，其中两种圆滑U形仅v1误通过。报告保留依赖规则源码哈希。初版报告另存`HEART_CANDIDATE_V2_INITIAL_20261122.json`。

这只是有限样例的规则对照，不是新真实模型成绩，不是生产通过率，也不证明所有非爱心形态都可排除。测试仍有Shapely旧参数弃用提示，不影响该次结果。

## 开发过程与边界

首轮检查39项通过、2项失败：GEOS将同一平底拆成多个相接线段，导致提前返回“截面不连通”，尚未产生平底检查字段。修正区间合并后，再增加圆底采样验证，最终44项通过。首轮记录保留`.local-dev/lower-taper-v2-_g4yziqv`。

目前v2消除了已发现的圆滑U形误放行，没有引入形状生成器或针对语料编号的分支。仍继承原自动检查的采样和形态近似局限；完整生产集成需要正常的规则分发及版本记录，不能把离线临时替换函数接入并发服务。

下一步应验证低位截面设置对尺度、平移、极浅底部、不同采样相位及真实模型计划的敏感性，确认是否仍有误拒/误放行；只有这些证据充分后才评估业务验收层集成，并继续并列保留旧评分。
