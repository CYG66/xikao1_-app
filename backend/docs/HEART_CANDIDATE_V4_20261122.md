# 限定参数曲线布局极值与离线候选v4

本轮没有修改生产应用、正式规则、模型提示或交付入口，没有调用DeepSeek。新增限定三角表达式的布局最低点证据，接入离线`cad.heart-acceptance-candidate.v4`；v3默认行为和历史报告保留。

## 复用与范围

将前一版Bezier布局追溯中已有的两次执行、点序核对、正比例缩放和平移计算提取为`evaluations/execution_layout_trace_v1.py`，供Bezier和参数式共同使用，没有复制两套布局推断。

`trig_layout_minimum_v1`只支持单个闭合参数轮廓、前一轮严格限定的三角表达式、可逐点验证的布局及无额外几何约束情况。表达式解析极值仍复用安全求值器；不增加采样或改写交付几何。

若布局导致重新采样、点数/点序不能用同一仿射映射核对，或者原式、区间、常量轴退化等不在范围内，返回未验证。采样误差仍标记为观测估计，不能称为全局数学保证。

## 历史参数式结果

响应3的原曲线最低位置在布局后对应约`(2000,1000)`毫米。实际映射：sx=1、sy≈0.9917365621、tx=0、ty≈−487.6048431毫米，逐点残差约9.36e−13毫米。源公式保持原样；原质量报告换算约0.4837316毫米，没有把该估计升级为严格上界。

其余既有检查、底部截面和可解析最低位置一致，因此该计划有资格在离线v4下通过。它并未成为正式候选，也没有改写原来失败轮的最终计划结果。

## 局限与下一步

v4仍继承旧形态/平滑经验判据及采样检查的局限。源极值是有限浮点解析计算，不是区间算术认证；支持范围有限，不能据此宣称任意参数式、任意布局或任意心形都可靠。

下一步应扩大真实已保存计划的离线回放，验证相位、尺寸布局、不同谐波系数以及旧规则已通过样本是否产生新误拒；再准备正常的版本化规则调用方案。当前仍用独立隔离进程作规则对照，不能将临时全局替换直接接入并发服务。没有更新70项通过率或声称生成能力提升。
