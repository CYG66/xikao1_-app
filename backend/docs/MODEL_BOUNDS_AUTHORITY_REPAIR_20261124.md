## 规则与实现

新增`cad_assertion_authority.reconcile_model_bounds`，在既有连接、尺寸和中心归一化之后、正式构造验收之前执行。它仅处理模型计划中的`bounds_size`，不修改坐标、圆心、半径、拓扑、用户原文或其他断言。

允许替代必须同时满足：

1. 去除模型断言的隔离试算能成功执行，仍保留几何及约束；试算不是交付。
2. 既有`verify_final_source_contract`基于用户原文与试算几何给出`status=passed`、`coverage=complete`。未知要求、尺寸错误或缺少完整覆盖均不适用。
3. 被替代断言选中的几何集合恰好等于整份已证明的几何，未知或局部目标不适用。
4. 实际世界外包框与模型断言确实矛盾；正确断言仍保留。

替代记录包含原断言、实测外包框、原模型数值、geometry_ids、完整来源证明和geometry_unchanged，随后重新执行普通构造、来源验收、候选门禁与保存。替代不是“忽略全部模型断言”，其他断言仍可能拒绝计划。

原先部件合并中的“省略旧错误外包框”特判已移至统一解释验收入口，避免只修复某一种合并路径。合并器仍保留其他断言和受保护几何；兼容原调用参数。原局部轴尺寸归一化逻辑保持原有边界。

完整来源证明目前只对现有测量器实际支持的来源有效，不能将本机制推广为所有图形、所有要求都能被独立证明。
