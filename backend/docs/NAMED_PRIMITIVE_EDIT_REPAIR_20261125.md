# 具名圆与矩形编辑目标绑定修复

本轮将原E1/E2编辑交付从**0/4提高到4/4**：两次左圆改半径、两次下矩形右移均正式保存，独立全图几何正确，原版本与非目标图形保持不变。复用既有编辑器、逻辑对象解析器和候选写入器，没有新增按编号的能力或生成器。

## 根因与实现

`parse_incremental_edit`原先支持场地/房间等对象的逻辑位置选择，但“左圆/下矩形”没有被带入目标字段；基础词汇门槛也未直接包含矩形，部分句子只因附带“其他图形”才被接受。候选中已有confirmed逻辑对象标签，信息不是缺失在几何层。

现有解析器扩展圆/矩形方向目标，将名称、位置及类型写入同一个`logical_object_selector`，并由既有`selected`出口传递给旋转/缩放/平移/尺寸等支持的操作。明确图元ID、实例与已有选择器的优先级不变；多个具名目标不会机械取第一个。

`resolve_logical_object_target`优先绑定唯一、已确认、同名的逻辑对象，记录`unique_confirmed_label`证据并返回现有geometry_refs。重复名称或缺少图元引用要求澄清，不能按位置猜一个；没有精确名称时仍使用原有类型/位置解析与评分阈值。后续版本、引用、几何编辑及验收保护保持原逻辑。

“圆”未指明哪一个，不会被解析成“左圆”；同名对象和同时提及两个目标的命令不默认选择单个对象。本轮不覆盖任意名称、所有图元类型或任意多目标编辑。
