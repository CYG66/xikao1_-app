# 独立凹口关系验证v1

本轮没有修改生产验收，没有新增生成器，也没有调用DeepSeek。新增评估侧`evaluations/notch_relation_v1.py`，版本`cad.notch-relation.v1`，与原形态窗口分开记录。

## 范围

对实际简单闭合边界测量中心竖线的上边界，再与左右采样峰值比较。若中央低于两侧超过0.5毫米测量容差，则在中央与较低峰值之间取横截面，检查是否有分居中心左右的两段分离区域。

不设凹口深度/全图高度的固定比例。0.5毫米是显式测量容差，不是用户提供的最小凹口尺寸；这仍是一套待验证的评估关系，不应直接推广为通用形状识别。

输出只有`relation_passed`；`formal_candidate_accepted`恒为false。它不检查全部爱心语义、底部收窄、光滑、对称、尺度及来源，也不能替代这些检查。U形可满足上部凹口关系但不能因此成为合格爱心，测试明确覆盖这一边界。
