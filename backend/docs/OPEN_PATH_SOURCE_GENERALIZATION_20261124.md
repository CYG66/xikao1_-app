# 开放折线来源覆盖与表示一致性（2026-11-24）

本轮继续修复“源要求→实际对象→测量证据→正式保存”衔接，范围为显式起点、逐段长度、首段绝对方向和后续相对转角的开放直线链。不新增图形生成器，不注入目标坐标，不依赖模型断言或语料编号。

## 能力复用与补充

已有`measure_path_geometry`能提供路径采样事实，已有S形关系检查能验证特定开放曲线，但原`verify_vertex_path`只覆盖原文直接给出顶点的闭合路径。它们不能把“第二段相对第一段再旋转多少度”直接形成完整来源证明。

本轮在共享测量模块增加只读`ordered_straight_path`：使用已有路径事实，从原文起点遍历实际线段，检查唯一连续开放链，拒绝断开、分叉、重复、回走、自交及额外非直线对象。图元存储顺序和方向不决定路径语义，共线细分不增加语义段数；测量不写回或修补CAD。

`verify_open_straight_path`挂接现有生产解释器、来源汇总与正式保存门禁，检查实际起点、段数、每段长度和绝对/相对方向。长度与起点使用共享0.5毫米容差，角度使用0.01度循环差值。报告保留原文证据、实际路径点、测量值和相关图元ID。只有原文全部被支持且所有检查通过才声明complete，未知后缀保持partial。

## 边界

- 原生直线和无bulge的开放多段线可混合；原生圆弧、样条、闭合轮廓不属于本次直线链证明范围。
- 支持有限的显式逐段语言，段数2至10；后续段必须明确连接前段末点、方向相对前一段。并非任意自然语言解析器。
- 使用米、厘米、毫米并按每个长度的单位换算；坐标必须有唯一明确单位。
- 零转角使来源中的逻辑分段点无法仅从共线几何唯一确定，此时返回partial与明确原因，不将合法共线几何错报为错误。未增加自动推断或新生成方式。
- 端点存在多个可接选择时拒绝猜测；单次路径测量最多4096条物理边。缺口不被写回吸附，绘图原数据保持不变。
- 胶囊等组合曲线的完整来源覆盖尚未解决，本轮不改其验收结论。
