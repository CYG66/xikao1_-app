# 来源参数到规划单位的衔接

本轮仅修改新项目，复用`cad_length_units.length_factors`和已有`requirement_contract`、`source_texts`，没有修改已有几何或生成器，也没有根据案例编号选择生产逻辑。

检查结果：已有米/厘米/毫米换算因子正确，录制失败包含模型把厘米数值重复缩小的情况。旧提示提供长度换算，但缺少带来源位置的统一坐标对照。该发现不等于证明提示改动就能消除模型规划波动。

## 改动

`planning_unit_contract`输出已有契约识别的有效标量、对象归属、比较操作、冲突信息，以及来源明确的圆心、中心、左下角、底边左端和起终点坐标。

每项保留source_id和原文范围，分别提供`plan_values.m`与`plan_values.mm`。例如圆心(-64,83)、坐标单位厘米，对应米[-0.64,0.83]、毫米[-640,830]。模型应按plan.units选取一次，不再乘原文单位因子。

标量只使用已有契约的effective事实，不把未识别长度或未绑定字段强行归给整体。坐标仅在同一来源的明确坐标单位唯一时换算；缺失或冲突时记为未解析。原文修订和部件作用域沿用既有契约，后端试算反馈不作为用户来源。

生产解释器的规划回调已收到该契约；构造执行仍遵守计划声明单位，原几何、来源和精度门禁不变。不通过缩放候选去猜测用户意图。
