# 结构诊断到有限修复的引用与连接衔接（2026-11-24）

本轮从最近真实对照的五次B组失败出发，只修复可证明的共同断点。不新增按语料编号或图形名称选择的生成器，不改既有19/24真实成绩。

## 录制证据

最小回放数据保存在`tests/fixtures/recorded_repair_reference_handoff.json`，来自本轮真实请求与响应：

- H2-r1-B：诊断的`affected_output_refs`为`assembly:closed_arch`，模型修复响应保留了四个原步骤的output_ref；旧合并器却仅按字符串匹配，因而错误认为这些步骤不在修复范围。
- R2-r3-B：模型已提供合法的shared_points表及表达式，但接缝归一化先尝试用ConstructionPoint/CompositeArcSegment验证`@point.x/y`，早于原有共享点解析，误报表达式错误。
- 同一R2计划的线、圆心、半径和端点集合已给出；两端圆弧的首尾角色与邻接线方向相反，后续自由端点绑定会造成错误路径。相切接缝可以独立判定有限的弧向/首尾选择。

## 修复

1. **共同引用目录用于修复范围。** `normalize_component_repair_context`复用`plan_reference_catalog`，将明确object/assembly引用展开到原有步骤输出，记录来源映射。规划提示、全部失败的结构重编译判定和部件合并使用相同展开结果。未知或歧义引用仍拒绝，不按显示名称猜测，不扩大受保护的局部坐标修复权限。重复归一化保持结果不变。
2. **先解析共享点，再测量连接。** 复合/旋转路径调用原有安全共享点解析器后进入接缝检查，保留修复记录。不存在的点、循环、非法数学表达式仍失败；没有新增表达式求值器。
3. **相切要求驱动有限弧向选择。** 新判定逻辑复用原段端点和切线测量工具，仅在原文要求相切/切向连续/平滑、圆弧两侧均为已连接直线时，枚举顺/逆时针与首尾角色选择。只有一个选择同时满足两侧连接及切线约束才采用；不修改圆心、半径、端点集合或段数。切线差最多0.01度，或模型给出的更严格值。原文给定弧向、起终角/点，否定相切，或多解时不猜测；已识别的长轴旋转不被当作圆弧行进方向。
4. **局部尺寸证明替代错误模型外包框断言。** 仅当去除自拟断言的试算几何通过独立、完整的源要求证明，且整体世界外包框断言失败、数值与原文局部长高匹配、引用覆盖完整对象时，移除该不适用的模型断言并保存证明。世界外包框数值正确的断言仍保留。未知来源、局部尺寸不符、其他范围或其他断言不因此解除检查。不会通过拉伸正确几何迎合错误断言。
