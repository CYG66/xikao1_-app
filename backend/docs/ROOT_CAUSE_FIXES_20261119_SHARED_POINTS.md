# 通用共享点与部件修复衔接

本轮只修改新后端。没有写入立方体的顶点坐标、连边模板或案例生成器，没有放宽几何验收。

## 实现

- 构造计划增加可选 `shared_points`，相邻图元可用 `@name.x` / `@name.y` 引用相同端点；派生点可使用既有受限数学表达式。
- 点依赖最多64项，检测缺失、循环、非法名称、非有限值、越界、额外坐标及参数t；计算仍使用既有 AST 白名单，不执行 Python 代码。
- 在计划校验前将引用解析为普通 CAD 坐标，保留现有执行和几何 IR。点表是初始构造记法，不是后续编辑中的持续参数约束；没有顶点自动吸附或坐标修正。
- 用户明确“只画N条棱线/直线段”且2≤N≤32时，模型输出契约要求明确边数和共享端点引用。没有具体图形的坐标或连接表。更大清单保留原通用输出契约，避免64个共享点的预算限制使输出无法表达。
- 部件修复在自己的作用域中解析新增点定义，可引用原计划已定义点；仅替换受允许的失败部件。受保护的步骤、原点表及调用者输入保持不变。
