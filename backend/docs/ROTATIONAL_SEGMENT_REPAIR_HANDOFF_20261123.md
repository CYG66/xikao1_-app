# 旋转单元诊断索引与修复衔接（2026-11-23）

## 已证实并修复的问题

复合路径自相交诊断的 conflicts 明细已经包含采样边和展开段映射，旋转路径也已有 seed_segment_indices、rotation_instances；本轮复用这些映射，没有另建检测器。

实际缺口是：顶层 affected_segment_indices 填入了采样小边编号，名称却表示曲线段。曲线采样后一个原始段可对应许多小边，直接按该编号修改原计划会定位错误。

现在明确分开：

- affected_sample_edge_indices：采样小边的零起算编号。
- affected_segment_indices：实际展开后的原始曲线段编号。
- affected_seed_segment_indices：add_rotational_path 原始单元 segments 数组的零起算编号，复用已有逐对映射汇总。
- effective_seed_segments：旋转周期端点约束生效后，实际执行的第一个单元；另附中心、请求方向和端点约束开关。

修复提示明确要求编辑原始单元，不把副本编号或采样边编号当成原始段编号；同时保留段间连接和周期首尾关系。证据没有提供替代坐标，不修改用户要求，不允许自相交图形通过。

仅修改 app/cad_construction.py 的诊断输出，新增默认回归测试及真实失败计划夹具。未新增齿轮生成器，未改变几何构造算法、验收条件或有限修复次数。原 xikao/backend 未修改。
