# 限定三角表达式的源极值候选

本轮新增离线测量`cad.trig-extrema.v1`，复用`cad_parametric.expression`进行安全校验、常数和曲线坐标求值。没有新增形状生成器、修改生产规则或调用DeepSeek。

## 限定范围

通过AST识别常数和三角函数的线性组合，不根据采样点猜测或拟合表达式。支持常数加一次sin，或常数加一次/二次cos的同族组合，以及外部常数加减乘除。参数区间必须有限递增且跨度不超过4π。

一次sin的导数零点来自cos=0；一次/二次cos组合的导数可因式分解为sin(t)与线性cos(t)因子，候选由sin=0及可行的cos值产生。候选加入区间端点后，使用已有安全求值器比较坐标值。

混合sin/cos、二次sin、相位偏移、乘积、幂、高频或更一般函数暂返回未验证。合法但暂不支持的表达式不被当成错误公式，也不会退回有限采样并声称证明极值。

结果是浮点解析候选，不是区间算术认证；源计划单位保持原样，没有应用布局或作最终交付判断。整轴恒定单独记录，不能凭有限候选冒充孤立最低点。

## 历史实际表达式

响应3的原式：

```
x = 2 + 2*sin(t)
y = 3 - 2*cos(t) - 0.6*cos(2*t) + 1.1
t ∈ [0,2π]
```

源坐标单位为米。测得x范围[0,4]，y最低值1.5，最高值约5.5333333。最低位置在t=0/2π，均对应(2,1.5)，为同一闭合接缝位置。

t=π对应顶部中央(2,5.5)，低于两侧峰值约0.0333333米。因此这一原式确有浅凹口，区别于最终另一份计划中央上凸的真实错误。该数值是布局前的源坐标深度，不能直接替代实际布局后毫米深度。

证据文件`.local-dev/TRIG_EXTREMA_20261122.json`保存原式、单位、全部候选、最低位置、顶部中央探测和实现哈希。
