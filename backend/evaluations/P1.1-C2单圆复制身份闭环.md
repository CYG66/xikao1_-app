# P1.1-C2：限定单圆复制与后续半径修改

2026-11-06。没有调用DeepSeek，没有修改历史测试记录，没有修改机器人执行或P0验收权限。

## 当前完成范围

后端生产编辑链已贯通：独立核验的已验收初始圆工程 → 自然语言复制 → 复制执行器分配ID及输出来源映射 → 原有确认门 → 版本持久化 → 仓库重新加载 → 自然语言“刚才复制的圆” → 目标解析 → 原有绝对半径修改 → 保存新版本。原圆全部参数保持不变，副本半径为500mm。

初始工程是由真实CAD执行器及独立尺寸断言建立的显式测试夹具，不是真实模型从自然语言创建的验证。测试没有替换目标解析、编辑执行器、保存函数或修改验收结果；按既有测试约定独立证明初始夹具的全部已声明要求后，赋予其测试基线验收证据。

## 调查与ID职责

- geometry_id：incremental_cad 的duplicate分支原本就使用max(id)+1；normalize_geometry_identity保留已有合法ID并拒绝重复。此次不替换分配算法。
- logical_object_id：由既有evolve_logical_graph_for_edit管理，几何成员实际字段是geometry_refs。只有现有图中有唯一归属时才记录，不补造对象名称。
- operation_id：执行器根据输入几何和编辑参数形成操作指纹；必须连同项目/版本绑定使用，不作为跨项目全局对象ID。
- variant_id：CreativeProjectStore.add_variant产生新版本，parent_variant_id限定来源版本；几何哈希只校验内容，不作为对象身份。

geometry_identity.py与cad_sketch_graph.py仅调查复用，没有重写或建立平行对象系统。已有symbol_table语义未变。

## 实际改动

1. incremental_cad.py：parse_incremental_edit只增加“刚才/上一步复制的圆”引用适配，操作部分仍由旧解析器处理；支持既有半径调整的“修改为”同义形式。duplicate分支在实际克隆处记录source id，edit_candidate_geometries将来源从临时内部字段取出，输出到edit.execution_identity。返回几何不附加元数据，避免破坏机器回放和几何比较。
2. cad_edit_contract.py：向后兼容增加execution_identity字段，build_cad_edit_contract携带执行器证据；不改现有操作类型与目标Schema。
3. cad_candidate_state.py：bind_creation_history核对父几何哈希、结果哈希、全部新ID、来源ID后，保存到现有reference_mapping扩展字段。绑定project_id、parent_variant_id、variant_id、geometry_hash；保留成员及操作来源。后续版本只延续哈希/版本相容的记录，删除后过滤已不存在成员；空记录不回退到更早对象。
4. creative_projects.py：add_variant在分配版本、校验ID并构建逻辑图后保存上述证据，仍经过原有事务与候选验收路径。
5. cad_target_resolver.py：recent_creation_selector和resolve_created_target只处理本轮的复制圆引用。严格检查当前版本绑定，唯一成员才解析；不存在、歧义或哈希不符要求澄清，不按坐标猜。
6. agent_service.py：在实际增量编辑入口、正式基线激活后消费来源证据；明确选区与复制引用冲突时拒绝，不覆盖旧选区。绝对半径仍走现有resize逻辑。结果新增向后兼容cad_edit_result，区分changed/no_change/execution_failed；最近复制目标解析失败保留明确失败结果。

自然语言路径：resolve_intent → parse_incremental_edit → _apply_incremental_candidate_edit → _activate_preview_variant_for_edit → resolve_created_target → edit_candidate_geometries → build_cad_edit_contract → 机器预览/确认 → _persist_candidate_edit → CreativeProjectStore.add_variant。

## 兼容性与回归过程

中断前的宽范围尝试曾将来源加进几何字典，导致机器校验及共享边界确认失败。已撤回此做法，改为独立执行证据；共享边界确认及正常复制、平移、选区回归重新通过。镜像、阵列、新增对象的临时来源标记和宽范围引用解析已撤回，只保留duplicate。

不是替换P1.1-A/B/C：源需求最终测量、断言聚合、旧符号表/保ID变换继续保留。本次只给旧编辑契约与版本元数据增加复制来源证据。旧版本缺少该字段时保持未知，不能凭几何位置猜补。

## 完成结论

限定的后端单圆复制→持久化身份→自然语言定位→绝对半径修改闭环已通过自动化生产编辑路径验证，可进行少量受限真实DeepSeek连续编辑测试，但本轮没有发起API请求，也未验证真实模型或App流程。

支持：刚才复制的圆、上一步复制的圆，以及复制出来的圆形式；既有普通选区与显式ID路径保持原机制。

不宣称支持：镜像/阵列/新增的来源引用、任意命名复杂部件、同一句复制后再修改、跨项目对象引用。到此停止，不推广到上述能力。
