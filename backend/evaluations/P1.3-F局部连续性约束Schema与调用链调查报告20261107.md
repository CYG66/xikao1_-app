# P1.3-F 局部连续性约束 Schema 与调用链调查报告

本轮为只读调查，未调用 DeepSeek、未修改生产代码、未修改 Schema、未改变 P0。

## 现有能力清单

`AddCompositePathStep` 当前提供：

- 全局 `continuity: C0 | C1`。
- 全局 `tangent_tolerance_deg`。
- 全局 `max_curvature`、采样误差、自交和重复段检查。
- `closed` 控制是否把末段与首段加入连接检查。

执行器 `_composite_continuity()` 通过段列表相邻位置计算切线角差，输出 `joint_count`、`failed_joints` 和 `maximum_tangent_delta_deg`。这是逐连接点测量证据，但不是逐连接点计划约束。

当前不支持：

- 每个 junction 独立声明 C0/G1/C1。
- 显式 `smooth`、`intentional_cusp`、`intentional_corner`、`unknown` 意图字段。
- 稳定的 segment ID 和 junction ID。
- 闭合首尾连接的独立约束。
- 逐连接点不同容差。

Bezier/样条段本身没有独立 `segment_id`；连接点通过数组相邻位置和闭合首尾隐式识别。几何重新采样和 ID 归一化后，验收报告只保留数组索引，不具备跨版本局部连接身份。

## A9 与 S1 对照

### A9

A9 是 4 段闭合 Bezier。现有报告可定位 4 个隐式 junction：段 1→2、2→3、3→4、4→1。计划只有整体 `continuity=C1`，没有任何局部意图。实际 2 个连接点切线失败，最大角差约 107.94°；左右叶瓣、凹口、下尖点和闭合语义另由通用爱心检查验证。当前无法从计划证明哪一个连接点是允许尖点，哪一个必须 G1/C1。

### S1

S1 是 3 段开放 Bezier。段 1→2、2→3 两个隐式 junction 均由整体 `continuity=C1` 检查，实际最大角差 0°，C1 通过。S1 的 source acceptance 后续已补齐为完整覆盖，但连接点仍没有稳定 junction 引用；保存后只能依赖当前段顺序和 curve-quality 报告。

## 生产调用链与首次缺失

实际链路：`agent_service._formal_cad_construction` → `cad_construction_interpreter.interpret_construction_request` → 模型返回 `CadConstructionPlan` → `execute_construction_plan` → `_validate_composite_path_quality` → `curve_quality` → `construction_acceptance_summary` → `cad_construction_commit` 保存。

原始自然语言中的“平滑”和爱心尖点主要进入提示词/语义文本；`AddCompositePathStep` 只接收整体 continuity。首次不可表达的位置是**需求契约/模型计划到复合路径局部连接约束的映射边界**。执行器能够测量每个隐式连接点，但没有计划字段告诉它“这个点允许尖点、另一个点必须 G1”。

现有局部修复可消费 `failed_joints` 诊断，但没有按 junction 保持其他段和尖点不变的控制点修复器。

## 最小 Schema 方案（本轮不实施）

如后续确认需要扩展，建议在 `AddCompositePathStep` 增加向后兼容的可选字段：

```json
{
  "junction_constraints": [
    {"junction_ref":"segment_1:end-segment_2:start","intent":"smooth","continuity":"G1","tangent_tolerance_deg":1.0},
    {"junction_ref":"segment_2:end-segment_3:start","intent":"intentional_cusp","continuity":"C0"}
  ]
}
```

该方案需要：复用段数组索引或新增稳定 segment_id；支持闭合首尾引用；允许 `unknown`；把原文 source_requirement_id 绑定到约束；输出逐 junction 证据。旧计划无该字段时继续使用现有整体 continuity，保持兼容。需要同步扩展 interpreter、construction validator、curve-quality 输出和 source acceptance，但不需要新几何对象系统。

## 后续最小建议

1. 先做只读证据扩展：为现有 `failed_joints` 输出稳定的 `segment_index`、连接坐标和两侧切线，保持旧 Schema 不变；用于确认 A9 具体失败点，避免猜测尖点位置。
2. 若真实需求持续需要混合意图，再实施可选 `junction_constraints`；优先支持 G1/C0/unknown，暂不引入自动控制点修复。
3. 对局部修复保持 blocked/partial，直到能证明修改一个 junction 不破坏尺寸、中心、拓扑和其他已通过连接点。

当前没有证据要求立即扩展 Schema。A9 的问题确实暴露了局部约束表达缺口，但 S1 证明整体 C1 对统一平滑曲线足够。下一步应先扩大离线证据，不自动进入生产 Schema 改造。
