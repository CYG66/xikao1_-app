# P1.3-H3.3/H3.4 多轮来源隔离与规划传递实施报告

本轮未调用 DeepSeek，未修改 H2 Schema、P0、对象身份或版本结构。

## H3.3

已实现 `inherit_requirement_source_index(...)`：

- 只从当前契约中的来源建立当前索引；
- 仅当旧来源原文完全一致时记录继承关系；
- 记录旧 contract_version 与当前 contract_version；
- 当前 request_id/project_id 重新绑定；
- 被当前契约删除的旧来源进入 `stale_previous_refs`；
- inferred/unknown 来源不会升级为可信来源；
- 旧来源不能单独授权当前 junction。

这保证项目切换、版本切换和多轮补参不会直接复用过期来源。

## H3.4

结构化 CAD 模型提示现在包含后端只读来源索引，明确模型不能创建或修改来源。模型返回 `junction_constraints` 后，解释器使用 `validate_junction_source_refs(...)` 校验：

- 引用存在且属于当前契约；
- smooth 与平滑/切向/C1/G1 语义匹配；
- cusp 与尖点语义匹配；
- corner 与折角/直角/转角语义匹配；
- cusp/corner 来源类型必须是 explicit/trusted_semantic；
- unknown 不产生豁免。

校验失败会拒绝计划，不进入 H4 正式几何验收，也不改变 P0 状态。
