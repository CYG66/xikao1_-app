## Agent A：自然语言理解与 CAD 规划

- 工作树：`cad-worktrees/nlp-planning`

- 交付物：`backend/evaluations/Parallel-A-NLP-CAD规划报告.md`

### 负责

1. 调查 A9 的真实模型请求与原始响应，确认 `junction_constraints` 在哪个阶段丢失（提示词未要求 / 模型未输出 / 解析丢弃 / 校验剥离 / 落库清空）。

## Agent B：CAD 几何与算法

- 工作树：`cad-worktrees/geometry`
- 分支：`parallel/geometry`
- 交付物：`backend/evaluations/Parallel-B-CAD几何算法报告.md`

### 负责

1. A9 第 1 段与第 6 段 Bezier 的控制点级分析：给出参数区间、交点坐标、采样误差上界。
2. 中央凹口回穿的形成机制：说明是控制点越界、切线方向反了，还是闭合段端点约束缺失。
3. 设计通用闭合轮廓的全局拓扑约束（非相邻段不得相交），并给出判定算法的时间复杂度与数值稳定性说明。
4. Bezier 控制点局部优化算法研究：在保持对称、尺寸、尖点意图的前提下做最小修正。
5. 自相交检测的精度与效率：与现有采样策略对照，给出"采样数 → 漏检率"的关系。
6. 目标：执行器不仅"能发现错误"，还能"安全地提出修复"，且修复不改变设计意图。

### 主要落点（可改）

- `backend/app/cad_construction.py`（`CadConstructionPlan` / `JunctionConstraint` / `AddCompositePathStep` 的几何执行）
- `backend/app/cad_plan_verifier.py`、`cad_local_repair.py`、`cad_constraint_solver.py`
- `backend/app/cad_sketch_graph.py`、`cad_structure_contract.py`
- 几何类验收：`cad_curve_fit_acceptance.py`、`cad_path_relation_acceptance.py`、`cad_relation_acceptance.py`
- 新增测试：`backend/tests/test_geometry_*.py`

### 禁止

- 改模型提示词与规划解析。
- 改来源校验（`cad_source_acceptance.py`、`cad_requirement_ledger.py`）。
- 放宽自相交判定标准（`allow_self_intersection` 只能由计划显式开启，不能默认放开）。
- 修改 A9 冻结几何去"制造成功"；不得写爱心/单一图形专用生成器。
- 未经审批改公共 Schema。

### 验收

- 报告中每个结论都带可复现脚本/命令与数值，不接受"看起来更平滑"这类判断。
- 修复算法必须给出「修复前后几何差异」与「意图保持」两项证据，并说明失败回退路径。
