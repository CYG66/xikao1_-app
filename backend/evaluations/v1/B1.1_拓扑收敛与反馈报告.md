- 分支：`v1/b1-topology`，基于上一版 commit `b519740` 新增 commit（未 amend、未合并、未推送）。
- 范围：仅 `backend/app/cad_construction.py`、`backend/app/cad_topology_safety.py`、B 线测试与本报告。未触碰 A 线三文件（`cad_plan_component_repair.py`、`cad_construction_interpreter.py`、`agent_service.py`）与 `agent_http_service.py`；未调用任何真实模型接口；未放宽 `allow_self_intersection` 或 H2/H3/H4 验收阈值；未改冻结输入与 D0 资产。

## 1. 本轮解决的问题

### 1.1 单段大尺度窄回环收敛（上轮未完成项）

上轮宽控包络回环（解析交点 (250,300)，t≈0.1127/0.8873）在模块内不收敛。本轮定位到两个根因并修复：

1. **内部节点被粗采样距离提前剪枝**：大子曲线样本漏掉交点时，样本间最小距离偏大，整枝被距离阈值剪掉。改为内部节点只做凸包分离剪枝，粗距离不再用于剪枝内部子树；距离验证只在叶级进行。
2. **叶弦投影残差不随细分收敛**：叶级点到弦投影的残差受弦高影响，无法压到容差内。交叉判定改为叶弦相交：两段叶弦方向号变号即证明交叉，接触点取弦交点，距离记 0；切线/近距仍走投影距离验证。

**显式收敛判据与预算上限**（写入模块 docstring 与常量）：

- 空间判据：子曲线控制凸包对角线 ≤ `leaf_size = max(4·tol, 0.0005·scale)`；直线恒为叶。
- 参数深度判据：细分深度达到 `SUBDIVISION_MAX_DEPTH = 16` 即截断。
- 节点预算：每次段对搜索独立计数，上限 `NODE_BUDGET_CAP = 8000`；自交二分深度上限 `SELF_HALF_DEPTH = 10`。
- **fail-closed 行为**：预算耗尽或深度截断时，若两凸包仍落在不确定带（`loose_band`）内，报告 `unresolved=True` 并记录 `near_contact` 几何反馈；不会假设路径 clear。预算耗尽是安全方向（宁可拒绝待复核，不放行未判定图形）。

### 1.2 `unresolved=True` 不再静默放行

- 门控决策改为：`(已确认接触 或 弦门相交 或 拓扑未决)` 且 `allow_self_intersection=False` 时拒绝。
- 未决且无已确认接触：`failure_scope="unresolved_topology"`，details 带 `unresolved_topology=True` 与 `escalation="replan_or_human_review"`，消息为“拓扑尚未判定，需重规划或人工复核”。
- 已确认接触：`failure_scope="intersecting_segments_only"`，沿用既有错误码 `self_intersecting_composite_path`。
- 与验收语义关系：本轮**没有**新增公共错误码、没有降低任何阈值、没有把“不确定”统计成“通过”；`allow_self_intersection=True` 的既有意图保持不变（计划明确允许自交时不阻断，但报告仍带未决标记）。是否把未决升级为独立阻断码，留待总控结合 H2/H3/H4 裁决。

### 1.3 通用几何反馈

`Contact` 反馈在既有段索引/参数/点/距离/类型基础上，新增双侧参数区间 `parameter_intervals`；接触类型枚举：

| kind | 含义 |
|---|---|
| `crossing` | 两段叶弦方向号变号，确认横穿 |
| `tangent` | 叶级投影距离 ≤ 邻近容差，未观察到方向号变号 |
| `self` | 单段 Bezier 自身两部分交叉 |
| `endpoint` | 接触点落在两段端点上 |
| `near_contact` | 深度/预算截断时仍在不确定带内，未决近距 |

规划器可据此定位“哪个段、哪段参数区间、什么类型的冲突”，反馈内容全部来自几何量。

## 2. Detection outcome 与 Generation outcome 分栏

**关键区分：检测出错误 ≠ 生成成功。** 本轮所有证据均属检测栏；没有任何一条被计为成功生成。

| 栏目 | 本轮能证明的内容 | 本轮不能证明的内容 |
|---|---|---|
| Detection outcome（检测） | 对给定几何输入，模块/门控能否正确识别交叉、切线、端点、自交与未决近距，并给出段索引、参数区间、类型与距离 | — |
| Generation outcome（生成） | — | 未运行任何真实模型生成；“拒绝了一个错误图形”不计为成功生成；规划器是否能依据反馈产出合法新方案，不在本轮证明范围 |

## 3. 案例前后结果与数值证据

### 3.1 单段三次回环（自交，上轮漏检）

- 控制点：`[(0,0),(1000,1000),(-500,1000),(500,0)]`；解析参考交点 (250,300)，t≈0.1127/0.8873。
- 修复前（上轮模块）：0 接触，未检出。
- 修复后（模块级）：1 个 `self` 接触，`unresolved=False`；参数 0.112705 / 0.887295，接触点 (250.0, 300.000000011)，距离 0.0，参数区间 [0.112701,0.112709] / [0.887291,0.887299]。
- 修复后（门控级）：拒绝，code=`self_intersecting_composite_path`，scope=`intersecting_segments_only`，contacts 含 `self` 接触。

### 3.2 混阶交叉（二次 Bezier × 三次 Bezier，独立同类案例）

- 段 0 二次 `[(0,0),(0,1),(1,1)]`；段 2 三次 `[(0,1),(0,0),(1,1),(1,0)]`；段 1 为连接线段。
- 结果：1 个 `crossing` 接触，段对 {0,2}，`unresolved=False`，接触点 (0.126733, 0.585259)，距离 0.0。
- 与 3.1 差异：非同段自交，而是两段不同阶数曲线横穿；阶数、控制点分布、冲突类型均不同。

### 3.3 端点接触

- 段 0 `(0,0)→(1,0)`，段 2 `(1,1)→(0,0)`，非相邻且共享端点 (0,0)。
- 结果：1 个 `endpoint` 接触，段对 {0,2}，点 (0,0)，距离 0.0，`unresolved=False`。

### 3.4 尺度不变性（同一形态放大/缩小）

- 回环形态 ×100（容差 1e-4）与 ×0.01（容差 1e-8）：两种尺度均检出 `self` 接触，`unresolved=False`。

### 3.5 阴性对照（不得误报）

- 分离双拱 `[(0,0),(0,1),(1,1),(1,0)]` 与 `[(0,3),(0,4),(1,4),(1,3)]`；平滑三次 `[(5,0),(5,4),(9,4),(9,0)]`。
- 结果：0 接触，`unresolved=False`。

### 3.6 arc/spline 弦近似误差边界

模块曲线级搜索只覆盖 line/bezier；arc/spline 仍由构造层折线兜底。圆弧等 n 等分弦高（矢高）边界：

`h_n = R·(1 − cos(Φ/(2n)))`，小步角 `h_n ≈ R·(Φ/(2n))²/2`（对步角二次收敛）。

实测表（R=100，Φ=90°）：

| 弦数 n | 矢高 h |
|---|---|
| 1 | 29.2893 |
| 2 | 7.6120 |
| 4 | 1.9215 |
| 8 | 0.4815 |
| 16 | 0.1205 |

残余风险：spline 无此类闭合弦高公式，其折线误差依赖构造层采样密度；arc/spline 段间平滑接触仍可能存在与 D1 同类的漏检，列入下一轮。

## 6. 残余风险与下一轮建议

1. **arc/spline 未纳入曲线级接触分析**：仍依赖折线兜底；spline 缺闭合弦高误差界。下一轮评估是否引入样条曲线级求交或补充采样误差估计。
2. **未决（unresolved）截断路径已闭环**（补测 commit）：确定性触发方式为测试内 monkeypatch 模块级 `NODE_BUDGET_CAP=5`（不依赖 wall-clock 超时），几何为两条凸包重叠、竖向间隙 5e-3（在邻近带之外）的凸拱。
   - 截断态断言：`unresolved=True`、无已确认接触；门控在 `allow_self_intersection=False` 下拒绝，`failure_scope="unresolved_topology"`、`escalation="replan_or_human_review"`、details 含 `unresolved_topology=True`。
   - 反向对照：同一几何、预算恢复默认 8000 时 `unresolved=False`、0 接触，证明未决只来自预算截断，不是几何本身性质。
   - 覆盖测试：`test_budget_exhaustion_flags_unresolved`、`test_gate_rejects_unresolved_topology`、`test_full_budget_resolves_separated_arches_as_clear`。
3. **段对内部接触条目偏多**：去重后报告层每对只保留最近一条，但搜索过程中叶级接触条目仍可能累积；下一轮可在搜索内按区域抑制重复叶接触，降低大轮廓耗时。
4. **D2 网格量化重复段、D3 容差复用、D4 证据上限**：本轮未处理，留待后续拓扑/证据增强。
5. **越界候选（未动手）**：若根本修复需触碰 A 线三文件、`agent_http_service.py` 或公共 Schema/验收语义，需总控裁决；本轮无此类改动。当前未引入新第三方依赖，公共接口未改变。
