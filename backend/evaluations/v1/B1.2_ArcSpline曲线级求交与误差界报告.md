## 1. 五个机制问题的回答

### 1.1 Arc 是否有可控误差上界

有闭合形式弦高（矢高）界。半径 `R`、总扫角 `Φ`（弧度）、等分为 `n` 段，每步角 `φ=Φ/n`，弧到替换弦的最大距离

`h_n = R·(1 − cos(φ/2))`。

- **保守上界**：由 `1 − cos x ≤ x²/2`，得 `h_n ≤ R·(Φ/(2n))²/2`。小步角下 `h_n ≈ R·(Φ/(2n))²/2`，对步角二次收敛；二次式是**保守上界**而非渐近近似，用它反解出的片数满足精确矢高界。
- **由目标容差反解 n**：`n ≥ Φ/2 · sqrt(R/(2·h_max))`（见 `arc_chord_count_for_tolerance`）。最坏情况取最大 `R`、最大 `Φ`；实现中弦高目标取邻近带 `h_max = PROXIMITY_FACTOR·tol = 2·tol`，因为低于邻近带的弦偏置不会被叶级投影漏判。
- **片数上限**：`ARC_MAX_PIECES=2048`。所需片数超上限时不假装已界住，标记该段对 `unresolved`（fail-closed）。

实测反解验证（精确矢高 ≤ 目标）：

| R | 扫角 | h_max | 反解 n | 实际矢高 |
|---|---|---|---|---|
| 100 | 90° | 1e-3 | 176 | 9.957e-04 |
| 1 | 90° | 1e-6 | 556 | 9.977e-07 |
| 10 | 180° | 1e-4 | 352 | 9.957e-05 |

### 1.2 Spline 能否建立保守误差界

样条没有单一曲率半径，采用**采样残差 × 保守放大系数**的可计算判据：

1. 在 `n` 个粗片上求值，再在 `2n` 细网格上求值；
2. 测量细样本到所属粗片弦的最大距离 `e`；
3. 保守界 `B = SPLINE_RESIDUE_FACTOR·e`（因子 3.0，覆盖样本之间未采样的拱起）；
4. `B ≤ h_max` 则以 `n` 片折线化；否则片数翻倍，直到 `SPLINE_MAX_PIECES=512`；仍不满足则 `unresolved`。

实测残差随密度下降（三次拱，尺度 100）：

| 片数 n | 保守界 B |
|---|---|
| 16 | 0.8717 |
| 32 | 0.2193 |
| 64 | 0.0549 |
| 128 | 0.0137 |
| 256 | 0.00343 |

**失效条件（明确列出）**：非均匀 / 非 clamped 节点向量；未夹紧端点的开口样条；控制多边形内部存在采样网格漏掉的环；阶数 >5；放大因子不足以覆盖局部高曲率尖峰。这些情形本轮不给出确定结论，走 `unresolved`。

### 1.3 真正切线能否与近距区分

判别不只看距离阈值：

- **交叉**：两片叶弦方向号变号（straddle）→ `crossing` / `self`，距离记 0；
- **端点接触**：双侧端点在 `tol` 内 → `endpoint`；
- **切线**：距离 ≤ 邻近带，且两叶弦夹角 ≤ `TANGENT_ANGLE_DEG=15°` → `tangent`；
- **未决近距**：距离在 `(proximity, loose_band]` 内不细分收敛，或子邻近带内夹角过锐（可能是叶级漏掉的浅交叉）→ 不标切线，记 `near_contact` + `unresolved`。

稳定区间：距离 ≤ `2·tol` 且夹角 ≤15° 接受为切线；距离落在 `(2·tol, loose_band]` 不做确定分类。**临界混淆情形**：极浅交叉（夹角近 0°、距离近 0）可能被误读为切线；此时叶弦若未 straddle 则保留未决，不强行分类。尺度变化下判别量（夹角、相对距离）随容差带缩放，已在 ×100 / ×0.01 尺度用例上验证一致。

### 1.4 预算耗尽是否保留 unresolved 而非错误确定性分类

是。截断（深度上限 16、段对节点预算 8000、自交二分 10 层）只产生 `near_contact` 条目并置 `unresolved=True`；**只有叶弦 straddle、端点匹配、或子邻近带平行接触**才给出确定分类。截断路径永不输出"确定无交"或"确定相交"。测试 `test_truncation_keeps_unresolved_and_no_definite_contact` 断言截断态所有接触类别 ⊆ {`near_contact`}。

### 1.5 合法几何误拒风险量化与可调参数

合法批量扫描（`test_legal_batch_has_no_unresolved_or_false_contact`，5 个独立夹具：分离贝塞尔拱、邻近带偏移拱、分离圆弧、分离样条、凸光滑三次）：**0 个 unresolved，0 个误报接触**。

可调参数与代价：

| 参数 | 调大的效果 | 代价 |
|---|---|---|
| `LEAF_SIZE_*` / 容差带 | 更少细分、更快 | 不确定带变宽，潜在漏检 |
| `NODE_BUDGET_CAP` | 更少截断、更少误拒 | 最坏情况耗时上升 |
| `ARC/SPLINE_MAX_PIECES` | 更紧弦高界、更少 arc/spline 未决 | 片对组合数上升，需包络预剪 |
| `SPLINE_RESIDUE_FACTOR` | 更保守、更少漏检 | 更难满足界，更多未决 |

### 2.2 Arc 专项

- **检出案例**：R=100 四分之一圆（圆心原点，0°→90°）与水平线 y=50 交叉；解析交点 x=√(100²−50²)=86.6025。检出 `crossing` 段对 {0,2}，点 (86.602, 50.0)，距离 0.0，`unresolved=False`。
- **阴性对照**：圆心 (0,0) 与 (300,0) 两枚分离四分之一圆；0 接触，`unresolved=False`。
- **误差界验证**：见 1.1 实测表；`test_arc_chord_count_inversion_satisfies_sagitta_bound` 断言反解 n 的矢高 ≤ h_max，且 n−1 超限。

### 2.3 Spline 专项

- **检出案例**：三次样条拱控制点 (0,0)(20,100)(80,100)(100,0) 与水平线 y=50 交叉；检出 `crossing` 段对 {0,2}，点 (17.284, 50.0)，距离 0.0，`unresolved=False`。
- **阴性对照**：两枚竖向分离样条拱；0 接触，`unresolved=False`。
- **残差界验证**：见 1.2 表；`test_spline_residual_bound_shrinks_with_density_and_meets_tolerance` 断言残差随密度下降且 256 片界 ≤1e-2。

## 5. 残余风险与下一轮建议

1. **spline 残差界偏保守**：因子 3.0 对高曲率尖峰可能不足；非均匀 / 开口 / 夹紧条件外的样条本轮直接未决，未做曲线级精确求交。
2. **稠密片对组合**：两片长弧深度重叠时片级包络预剪后仍可能产生较多叶级检查；当前有节点预算兜底，未做空间索引。
3. **切线临界混淆**：极浅交叉与切线的区分依赖叶弦夹角；更深的细分收敛判据可在下一轮补强。
4. **D2 网格量化重复段、D3 容差复用、D4 证据上限**：本轮未处理。
5. **越界候选（未动手）**：若根本修复需触碰 A 线三文件、`agent_http_service.py` 或公共 Schema / 验收语义，需总控裁决；本轮无此类改动，未引入新第三方依赖，公共接口未变。
