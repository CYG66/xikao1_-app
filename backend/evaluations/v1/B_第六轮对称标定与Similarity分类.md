## 1. A 块：镜像对称测量标定

### 1.1 机制（不依赖形状名称）

绕质心构造 180 箱径向剖面 `r(θ)`，扫描 72 个候选镜像轴方向，对每个轴比较镜像角对
`prof[α+φ]` 与 `prof[α−φ]` 的归一化残差（除以平均半径）。判定取**最差镜像角的最大残差**
（median / p90 仅作记录量，不用来定判），避免单个未配对扇区被良性中位数掩盖。

- 角度覆盖空缺 > 5%（开口 / 半圆 / 只画一半）→ 直接 `undetermined`，fail-closed。
- 残差按平均半径归一化，结论与绝对尺度无关。

### 1.3 三项误判率与样本量

| 指标 | 分子 / 分母 | 比率 |
|---|---|---|
| 误判非对称（正向被拒） | 0 / 5 | 0/5 |
| 误判对称（负向被直接判 symmetric） | 0 / 3 | 0/3 |
| 边界带 near_symmetric（负向，未接受为对称） | 2 / 3 | 2/3 |

### 1.4 非目标部件不得填补目标对称缺失

| 用例 | 实测 verdict | 记录 p90 |
|---|---|---|
| 目标部件只取一半点集 | undetermined | inf |
| 朴素拼接：目标半集 + 相邻镜像部件 | symmetric | 7.311e-05 |

**结论与局限（已查证 + 推断）**：
- 只传目标半集时正确落 `undetermined`；
- 一旦把相邻镜像部件拼进同一点集，场景整体看起来对称，探针会判 `symmetric`。
- **当前实现没有 `target_ref` 点集过滤**：调用方必须只传入目标部件的点集；若上层把场景全部
  点集塞给对称检查，非目标部件会填补目标的对称缺失。这是接入前必须补上的过滤责任（见 §1.7）。

### 1.5 三类容差分离（不得混成一个数）

| 容差类别 | 取值 | 来源 / 依据 | 风险标注 |
|---|---|---|---|
| **数值容差**（浮点 / 归一化阈值） | `SYM_BAND=0.05`、`NEAR_BAND=0.15`（归一化最大镜像残差） | **新增量**：在本矩阵上标定，未复用既有生产容差；残差按平均半径归一化 | 边界带 0.05–0.15 内的不对称只能落 `near_symmetric`，不能当对称；带宽误杀/漏杀风险见 §1.6 |
| **采样误差**（离散化残差） | 180 角度箱；样例 300/1000/2000 点；密度档残差波动 1.3e-2 ~ 1.6e-2 | 由采样密度敏感度矩阵实测 | 开口/稀疏对象覆盖空缺 >5% 直接 `undetermined`；本原型未对弧/样条弦高单独建界（生产侧 B1.2 已有保守弦高界） |
| **用户容差**（业务可接受偏差） | B 线不自设 | 留需求语义侧（C / 需求）按业务偏差定义 | 若把用户容差混进数值阈值，会把"业务可接受的不对称"误判为几何对称 |

### 1.6 残余风险与已踩死路（如实记录）

1. **边界带判别力不足（已查证）**：2/3 局部凸起负向落在 `near_symmetric`（0.049 / 0.067），
   原型只能分离粗粒度不对称；0.05–0.15 之间的细不对称尚不能稳定判 `asymmetric`。
2. **轴角估计受分箱分辨率限制（已查证）**：方形径向剖面在 180 箱分辨率下轴角估到 22.5° 族，
   与真实 0/45/90 轴有偏差；方向维只验证结论不变，未验证轴角精度。
3. **一阶径向谐波是偏心圆（数学事实，推断）**：`r=1+a·sinφ+b·cosφ` 描述的仍是一个偏心圆，
   关于偏心方向成轴对称，不能用作"无对称轴"负向；本轮负向最终改用局部高斯凸起构造。
4. **最近邻点级匹配在稠密闭合曲线上平凡命中（已弃用）**：反射点总能在邻近采样点找到近距离
   匹配，无法识别径向不对称；现判据改为角度对应的径向剖面残差。
5. **无 `target_ref` 过滤（已查证）**：见 §1.4。

### 1.7 对称能否升格为生产门禁：**本轮不能升格**

**判断（已查证 + 推断）**：对称检查本轮只跑 **Shadow**，不得设为强制生产门禁。证据不足项：

- 负向边界带判别力不足：2/3 细不对称只能落 `near_symmetric`，没有稳定的 `asymmetric` 分离；
- 轴角估计精度未达标（22.5° 族偏差）；
- 样本量仅 21 行，曲线族覆盖限于圆 / 椭圆 / 方形 / 平滑环 / 径向凸起；arc、spline、开口、
  自交邻域尚未标定；
- 缺目标部件过滤机制，场景级点集会被非目标部件误导；
- 数值带宽 0.05/0.15 是新增量，尚未与业务用户容差对齐。

**升格前还需补的证据**：更多曲线族（arc/spline/开口/近切/自交）的正负向标定矩阵；边界带
残差分布与误杀/漏杀量化；`target_ref` 过滤接入；轴角分辨率加密或改用点-剖面混合残差。

## 2. B 块：Similarity 五级分类

### 2.1 级别与机制

级别：`identical / equivalent / similar / different / undetermined`。

混合机制（不只看 Hausdorff）：
- 双向最近点归一化 Hausdorff（按包围盒对角线归一化）；
- 闭合状态匹配；
- 自交个数匹配（采样弦跨立粗计数）；
- 拓扑不匹配（闭合不一致或自交个数不一致）→ 直接 `different`，不再看距离。

带宽（**新增量**，归一化 Hausdorff）：`IDENT_BAND=1e-12`、`EQ_BAND=0.02`、`SIM_BAND=0.08`。

**口径纪律（已查证）**：
- `similar` **不是** `equivalent`：形状接近 ≠ 轨迹等价；`similar` 是**放行**信号而非拦截信号，
  下游不得把 `similar` 当等价用，也不得因曲线接近就停止修复。
- 证据不足（缺几何点集）→ `undetermined`，不猜。

### 2.2 similar 侧逐条清单（6 例，期望 similar/equivalent/identical）

| # | 样例 | 实测级别 | 归一化 Hausdorff | 拓扑（闭合/自交对） | 判定依据 |
|---|---|---|---|---|---|
| 1 | 圆 r1.5 vs r1.7 | similar | 4.159e-02 | True / (0, 0) | 同族近距，拓扑一致，超出等价带 |
| 2 | 圆 vs 微椭圆 1.5×1.35 | similar | 3.536e-02 | True / (0, 0) | 同族近距 |
| 3 | 椭圆 2.2×1.0 vs 2.0×1.1 | similar | 4.138e-02 | True / (0, 0) | 同族近距 |
| 4 | 豆形 vs 微扰豆形 | equivalent | 1.727e-02 | True / (0, 0) | 落在等价带 0.02 内 |
| 5 | 平滑环 vs 1.1× 缩放 | similar | 3.675e-02 | True / (0, 0) | 同族近距，整体缩放 |

结果：**6/6** 接受为 similar 或更优，无被推到 `different` 的同族近距样例。

### 2.4 边界口径说明

- 方形 → 平滑环 / 圆角方形：本口径判 **different**。二者拓扑都保持闭合、自交 0，但归一化距离
  0.086–0.109 超出相似带 0.08，且属跨族轮廓；`similar` 只保留同族近距。
- 等价带 0.02 与相似带 0.08 之间为 `similar`；0.08 以上、拓扑一致为 `different`；拓扑不匹配
  不论距离直接 `different`。
- 带宽为新增量，误杀风险：同族但形变略大的合法几何可能被推到 `different`；漏杀风险：跨族但
  轮廓接近的对象可能留在 `similar`。本矩阵未量化这两个方向在真实分布上的比例。
