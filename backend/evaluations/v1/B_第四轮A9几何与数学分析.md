## 0. 被测曲线（逐字取自案例记录）

```
x(t) = 2 + 2 sin t
y(t) = 3 + 2 cos t + 2 sqrt(|sin t|) cos t
```

- 首轮参数域 `t ∈ [0, 2π]`；修复轮 `t ∈ [−π, π]`；两轮 `x/y` 表达式逐字相同。
- 后端实测特征（两轮一致）：`center_notch=true`、`left_upper_lobe=true`、
  `right_upper_lobe=true`、`lower_tip=false`；失败检查 `heart_bilateral_lobes_notch_and_lower_tip`。

## 1. 两轮是否同一轨迹

**结论（已查证）：两轮是同一几何轨迹（点集等价），修复轮只改了参数域，未改几何。**

### 1.1 周期依据

- `sin t`、`cos t` 为 `2π` 周期；`|sin t|` 为 `π` 周期，故 `f(t+2π)=f(t)`，曲线至少 `2π` 周期。
- 探针检验 `f(t+π)` 与 `f(t)` 的最大偏差为 **6.2433**（已查证），说明曲线**不是** `π` 周期；
  因此区间从 `[0,2π]` 平移到 `[−π,π]` 不是"半个周期重复"，但两个区间长度均为 `2π`。
- 模 `2π` 覆盖：`[−π,0]` 平移 `2π` 后落在 `[π,2π]`，`[0,π]` 保持原位，
  故 `[−π,π]` 模 `2π` 覆盖完整 `[0,2π]`；两区间的像集相同。

### 1.2 数值对照（探针，2001 点/区间）

| 量 | `[0,2π]` | `[−π,π]` |
|---|---|---|
| 包围盒 x | [0.0000, 4.0000] | [0.0000, 4.0000] |
| 包围盒 y | [0.007621, 5.992379] | [0.007621, 5.992379] |
| 弧长 | 19.417918 | 19.417918 |
| 双向 Hausdorff | a→b 3.130e-08；b→a 9.017e-15；max **3.130e-08** | — |

3.13e-08 为采样网格对齐误差量级，远小于既有连接/邻近容差（`1e-6` 量级）；
包围盒与弧长逐位一致。**判定：几何等价，修复轮未产生任何几何改变。**

## 2. t=π 附近的局部结构：外凸尖点还是内凹

**结论（已查证）：t=π 处是底部中心的内凹点（notch，朝内），不是朝外的下凸尖点；
曲线真正的最低点在左右两侧叶，底部中心反而抬高。**

### 2.1 局部取值（探针）

令 `u = t − π`，邻域采样：

| u | t | x | y |
|---|---|---|---|
| −0.050 | 3.0916 | 2.09996 | 0.555938 |
| −0.010 | 3.1316 | 2.02000 | 0.800112 |
| −0.003 | 3.1386 | 2.00600 | 0.890465 |
| 0 | 3.1416 | 2.00000 | **1.000000** |
| +0.003 | 3.1446 | 1.99400 | 0.890465 |
| +0.010 | 3.1516 | 1.98000 | 0.800112 |
| +0.050 | 3.1916 | 1.90004 | 0.555938 |

中心 `(2,1)` 两侧 `|u|=0.003` 处 `y=0.8905 < 1.0`，即中心是局部 **y 极大**：
从中心向左右两侧下行。沿闭合边界的法向看，这是朝轮廓内部凹进的 V 形口，
不是朝外扎出的下尖点。

### 2.2 单侧导数 / 斜率 / 曲率（有限差，h=1e-3）

| 侧 | 速度 (vx, vy) | 斜率 dy/dx | 曲率 κ |
|---|---|---|---|
| 左 u<0 | (−2.000, +44.719) | −22.36 | 1478 |
| 右 u>0 | (−2.000, −44.719) | +22.36 | 1478 |
| 正则点 t=π/2 | (0.000, −4.000) | — | 0 |

两侧切线斜率符号相反、绝对值很大（近竖直），曲率相对正则点显著放大；
因 `√|sin t|` 在零点不可导，速度 y 分量在极限下发散，有限差值随步长变化，
**曲率绝对值属待验证量**，但其"两侧切线方向不连续、局部高曲率"的定性结论稳定。

### 2.3 全局最低点位置（探针）

- 最低两点：`(2.8058, 0.007621)`（t≈2.727）与 `(1.1942, 0.007621)`（t≈3.556），
  左右关于 `x=2` 镜像（1.1942+2.8058=4.0000）。
- 顶部最高点 `y≈5.9924`，同样为左右双峰。
- 即底部轮廓是"两侧低、中间抬高"的双叶 + 中心上凹，缺少爱心要求的**单一中心下尖点**。

### 2.4 与后端检测器口径的对照（已查证规则回放）

检测器 `lower_tip` 规则（归一化到包围盒 [0,1]）：
`|x−0.5| < 0.1 且 y < 0.01`。

- t=π 中心底点归一化坐标 `(0.5000, 0.1658)`：x 带内但 **y=0.1658 不满足 <0.01**。
- 两侧最低点归一化 `(0.2985, 0.0000)`、`(0.7015, 0.0000)`：y 满足但 **x 带外**。
- 无任何点同时满足两条件 → `lower_tip=false`。

**判断：在该规则口径下，检测器与几何一致，不是把存在的中心尖点漏报；
几何本身就没有落在中心底部的下凸尖点。** 检测器阈值（x±0.1、y<0.01 归一化）
是否对"浅尖点"过严，属检测器调参问题，需 H4 验收语义裁决，本轮不放宽、不改动。

## 3. 通用尖点 / 转折识别判据（不依赖爱心形状）

### 3.1 候选临界点提取（组合判据，非单阈值）

对任意参数曲线 `r(t)=(x(t),y(t))`，在密集采样上找满足下列任一组合的位置：

1. **速度局部极小或退化**：`‖r'(t)‖` 在邻域内取极小；正则尖点速度趋于 0，
   本曲线这类参数奇异点速度发散，故不能只看速度零点。
2. **切线方向突变**：左右单侧切线方向角之差超过邻域正则样本的角度散布；
   本案例两侧斜率 ∓22.36，方向近竖直且符号反转。
3. **曲率尖峰**：`κ=|x'y''−y'x''|/‖r'‖³` 相对正则样本中位数显著放大（本案例 1478 vs 0）。
4. **双侧极限不重合或分支分叉**：两侧极限点重合但离开方向不同；或同参数邻域出现两支。

### 3.2 外凸尖点 vs 内凹尖点（notch）

在候选点两侧取弧长窗口内的邻弦，比较候选点相对邻弦的法向偏移方向：

- **外凸尖点（朝外）**：候选点沿轮廓外法向落在邻弦之外，是局部外极值；
  闭合曲线上表现为该点比两侧邻点更远离内部区域。
- **内凹尖点（朝内）**：候选点沿内法向落入邻弦围成的内侧，是局部内极值；
  本案例 t=π 两侧邻点 y 更低，中心抬高，属此类。

内部侧方向由闭合曲线走向（绕向/面积符号）确定，不按形状名称推断。

### 3.3 阈值来源（不自创通过阈值）

- 点重合/邻接判定复用既有 `connection_tolerance` / 邻近带 `1e-6` 量级；
- 邻弦窗口按局部弦长比例取，不写固定像素角；
- 曲率放大倍数以同一曲线正则样本的中位数为基准；
- 角度散布以邻域样本切线角标准差为基准。
- 任何低于证据分辨率的临界位置，按 B 线既有 fail-closed 口径记未决，不强行分类。

## 4. 通用识别"只改参数域、轨迹等价"的修复

### 4.1 不依赖字符串比较的等价判据

对修复前后两条参数曲线：

1. **点集距离**：密集采样后计算双向 Hausdorff，按包围盒对角线归一化；
   同时记录最大/中位最近邻距离。
2. **全局几何量对照**：包围盒宽高、弧长、质心、（可选）二阶矩/面积，差值在容差内。
3. **参数重映射检验**：对 A 采样点在 B 上找最近邻，检验最近邻参数是否构成单调
   双射；重映射残差小则存在保序参数等价。
4. **拓扑特征对照**：交叉数、极值/尖点个数与角色——度量接近不能替代拓扑一致。

### 4.2 探针量化基线

| 对照 | 归一化/绝对 Hausdorff 最大值 | 判读 |
|---|---|---|
| 两轮同曲线（`[0,2π]` vs `[−π,π]`） | 3.130e-08 | 等价（网格误差量级） |
| 故意改号变体（`+2√|sin|cos` 改为 `−2√|sin|cos`） | **1.6518** | 明确不等价 |

### 4.3 双向误判风险

- **误判"真改动"为等价**：Hausdorff 只度量点集距离，看不到内部自交、尖点个数、
  连通性变化；两条度量接近但拓扑不同的曲线会被误并。缓解：叠加第 4.1 第 4 项拓扑对照。
- **误判"等价"为真改动**：采样过疏、尺度/旋转未归一化、参数方向翻转导致重映射失败；
  缓解：密度按局部弦长自适应，归一化后再比对，方向翻转单独识别而非判不等价。
- **待验证**：本探针仅一组等价 + 一组改号变体，误判率需更多曲线族样本估计，单案例不给比例。

## 5. 诊断如何约束下一轮规划（通用，非爱心专用）

1. **显式临界点声明**：规划器必须把轮廓上的局部极值、尖点/转折、连接点作为
   结构化约束列出（角色：外凸尖点 / 内凹口 / 侧叶峰；位置或相对对称轴的关系），
   不能依赖表达式隐式长出结构。
2. **对称轴约束入计划**：左右对称应落成可校验的对称轴/镜像约束，而不只写进语义标签；
   对称关系与宽高、中心尺寸一并保留。
3. **极值可定位**：下尖点这类要求应给出预期位置（如底部中心轴上）与外凸角色，
   便于后端按第 3 节判据复核；缺少该声明时，检测侧按未决/缺失特征处理，不推定合法。
4. **不改尺寸与对称**：修复只允许调整缺陷结构，宽高、中心、对称关系保持原值。
5. 本轮不新增任何针对 A9/爱心的专用控制点序列或分支；上述约束对任意自由轮廓通用。

## 6. 是否需要通用"几何进展检测"——B 线意见

**需要。** 当前有界修复可以把"参数区间变化"当作一次修复进展，即便几何点集等价
（本轮两轮即如此，修复 1 次但几何零改变）。建议在修复链路补一个**几何差异门禁**：

- 修复前后按第 4.1 节做点集距离 + 拓扑特征对照；
- 等价表达式/参数域改动**不计为有效修复进展**，不消耗修复预算计入成功率；
- 几何差异证据（Hausdorff、极值/尖点个数、特征对照）入证据账本，与 detection/generation
  分栏统计一致。

该门禁属通用几何机制，不绑定爱心；具体接线是否触碰 A/C 线受保护文件，需总控裁决，
本轮未动手。

## 6A. 可调用判据原型（供 C 线直接消费）

原型文件：`backend/evaluations/v1/probes/b_round4_geometry_criteria.py`
（离线探针，非生产代码；纯标准库，无模型/网络调用）。自检四条全部通过，
输出见 6A.5。

### 6A.1 轨迹等价判定

**函数签名**

```
trajectory_equivalent(spec_a, spec_b, tolerance) -> EquivalenceResult
```

```
EquivalenceResult:
  equivalent: bool                 # 点集 + 包围盒 + 弧长均在容差带内
  undetermined: bool               # 字段缺失/域非法时为 True，绝不默认等价
  reason: str
  hausdorff: float                 # 双向最大 Hausdorff 距离
  directed: (float, float)         # a→b, b→a 有向距离
  bbox_delta: (float, float)       # 宽、高包围盒差
  arc_length_delta: float
  remap_residual: Optional[float]  # 参数重映射残差（原型暂留接口，未计算）
  counterexample: Optional[((x,y),(x,y))]  # 最大距离反例点对
```

**输入（C 必须从计划/几何取；任一缺失返回 `undetermined=True`，不得判等价）**

| 字段 | 含义 | 缺失处置 |
|---|---|---|
| `fn` | 参数求值器 `t -> (x, y)`（参数曲线）；或已采样点列（arc/bezier/spline 由执行器先离散化） | 无法判定 |
| `t0, t1` | 参数区间端点 | 无法判定 |
| `samples` | 采样密度（须 ≥8） | 无法判定 |
| `tolerance` | 既有连接/采样容差（`connection_tolerance` / `max_sampling_error`） | 无法判定 |

**判定机制**：双向 Hausdorff + 包围盒宽高差 + 弧长差同时落在容差带内才判等价；
反例点对随结果返回，供复核。拓扑特征（交叉数、尖点个数）对照在第 4.1 节第 4 项，
原型未内建，属后续接线项。

### 6A.2 外凸尖点 / 内凹点分类

**函数签名**

```
classify_boundary_feature(closed_polyline, index, tolerance, window=4) -> CuspResult
```

```
CuspResult:
  role: outward_cusp | inward_notch | regular | undetermined
  undetermined: bool
  reason: str
  tangent_left_deg, tangent_right_deg: Optional[float]
  angle_gap_deg: Optional[float]     # 两侧切线方向夹角
  curvature_ratio: Optional[float]    # 局部转折角 / 正则样本中位转折角
  side_sign: int                       # +1 朝外, -1 朝内, 0 未知
  evidence: dict                       # 法向偏移、质心方向、窗口
```

**输入字段**：有序闭合点列、候选点索引、既有容差；邻弦窗口 `window`（采样点数）。
内外侧由候选点相对邻弦的法向偏移与指向质心方向的符号关系判定：同向为朝内凹口，
反向为朝外尖点，不按形状名称推断。

### 6A.3 C 线消费字段清单（修复是否真改了轨迹）

C 判断"本轮修复是否实质改几何"时，应从计划/几何记录取：

1. 段类型（line / bezier / arc / spline / parametric）；
2. 控制点或参数表达式（bezier/spline 控制点列；arc 圆心/半径/起止角；parametric 的 x/y 表达式）；
3. 参数区间 `t_start/t_end`；
4. 闭合标志与有序点列；
5. 既有容差：`connection_tolerance`、`max_sampling_error`、邻近带；
6. 采样密度与离散化方式。

字段缺失或无法离散化 → 返回 `undetermined`，**不得**记为等价、也不得记为有效修复进展。

### 6A.4 阈值纪律

- **复用既有量**：距离判定使用调用方传入的 `connection_tolerance` /
  `max_sampling_error`；邻近带沿用既有 `PROXIMITY_FACTOR(2.0)·tol`，未新设通过阈值。
- **新增量（明确标注）**：`window=4`（邻域半宽，采样点数）为原型新增旋钮。
  - 误杀风险：窗口过小会把采样噪声/近切抖动读成尖点；
  - 漏杀风险：窗口过大会平滑掉真实锐特征；
  - 生产化方向：窗口按局部弦长比例自适应，而非固定点数。
- `curvature_ratio`、`angle_gap_deg` 仅作为**证据数值**上报，原型未把它们写成
  通过/拒绝硬阈值；角色判定依据法向偏移符号。
- 未为让 A9 通过而自定任何数值；本案例 `lower_tip` 阈值属检测器 H4 口径，本轮未改。

### 6A.6 自交与近切情形下的误判边界

- **自交**：若候选点邻域内存在跨段交叉，内部侧方向不唯一，分类必须落
  `undetermined`，不得在自交环上判外凸尖点。原型目前仅做粗粒度包围盒提示；
  生产应复用 B 线拓扑模块的弦跨立（chord-straddle）求交结果作为前置过滤。
- **近切（两曲线相切/贴近）**：本分类器只处理单条闭合边界上的特征，不合并两条
  曲线；两曲线间的接触仍归拓扑模块的 `tangent` / `near_contact` 判定，避免把
  两线近切误读成某条边界的尖点。
- **临界混淆**：低曲率浅凹口在容差附近可能落入 `regular`；该情形按 fail-closed
  记未决，不强行归类。

## 7. 残余风险与待验证项

1. **待验证**：t=π 附近曲率绝对值依赖有限差步长；`√|sin t|` 零点处的解析阶数
