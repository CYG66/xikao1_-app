## 3. 时序证据：环境变量先于模块导入与单例初始化

## 7. 密钥零泄漏自检

脱敏实现：`d1_round4_isolation_collector.py` 的 `redact()` 递归处理字典/列表/字符串；按字段名（`api_key` / `authorization` / `key` / `token` / `secret` / `api-keys`）整体替换为 `<redacted>`；字符串值经正则覆盖 `sk-…`、`Bearer …`、`key=…` 等密钥形状。`flush()` 写出前再跑 `assert_no_secret_shape`，发现密钥形状即中止。

自检样例（合成夹具，非真实凭据）脱敏结果（快照 `offline.redaction_sample`）：

- `Authorization` → `<redacted>`
- 嵌套 `api_key` → `<redacted>`
- 含 `token=…` 的纯字符串 → `<redacted>`

样例序列化后 `redaction_secret_shape_absent = true`。对 `v1/` 全部 JSON/JSONL/MD/PY 做密钥形状扫描：除自检脚本内**合成夹具**与正则常量本身外，无真实密钥串；报告、账本、Git 变更中均不含 Key 片段。
