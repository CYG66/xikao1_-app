# 后端代码职责说明

核对日期：2026-11-02。依据当前目录、启动入口、路由、函数声明及《模块边界.md》整理。本文件说明职责，不代表所有实现均已完成或通过验收；本轮未逐行审计所有源码和历史测试产物。

## 目录

- `app/`：线上后端实现。
- `tests/`：自动回归测试；`tests/manual/`：真实供应商、多轮语料、App 回放和产品验收脚本。
- `evaluations/`：固定评测语料及报告；报告目录中的项目、会话和数据库属于测试隔离产物。
- `tools/`：开发与转换辅助工具，不能整体视为线上入口。
- `wheelhouse/`：离线安装依赖包。
- `.local-ai-test/`：本地 AI 测试运行数据；`.backup_step1/`、`app.zip`：历史备份；缓存目录不参与业务设计。
- `.test-task-store*.json`、日志、临时报表：历史测试产物，不是生产源码。

## 启动和 HTTP

- `main.py`：创建 FastAPI，注册路由、中间件；启动/关闭 ROS 适配、项目同步、设备发现。
- `routers/system.py`：健康、状态、网络、日志、数据库维护接口。
- `routers/agent.py`：聊天、模型配置、会话、运行记录、审计、案例及模板管理接口。
- `routers/projects.py`：项目增删改查、生成候选、保存图纸、选方案、规划、执行、恢复和报告接口。
- `routers/drawings.py`：图纸读取、导入、保存和编辑相关接口。
- `routers/missions.py`：任务接口。
- `routers/device.py`：底盘速度、急停、喷码机、全站仪与设备诊断接口。
- `routers/rosbridge.py`：状态与 ROS 桥 WebSocket。
- `schemas.py`：接口请求/响应数据结构和输入校验；`config.py`：运行配置；`web_demo.py`：演示中间件。

## AI 对话和编排

- `agent_http_service.py`：HTTP 请求上下文准备、同步/流式聊天、运行记录衔接、候选展示过滤。
- `agent_service.py`：主业务编排，处理路由、补参、构造、编辑、工具调用、确认和结果；当前仍是大型交叉模块，不能仅凭文件拆分认定职责完全隔离。
- `agent_service_context.py`：上下文与需求合并辅助；`agent_service_policy.py`：提示词和工具集合；`agent_service_config.py`：供应商静态注册。
- `agent_policy.py`：基础/进阶模式工具权限；`tooling.py`：工具定义和参数契约。
- `agent_response_builder.py`：把内部验收记录适配为公开响应摘要。
- `conversation_memory.py`：多轮对象记忆、引用消解、需求和会话上下文；`conversation_archive.py`：归档与回收站信息；`project_ownership.py`：项目所属会话上下文。
- `agent_attachments.py`：附件元数据和上传校验；`knowledge_retrieval.py`：内部知识检索；`answer_validation.py`：回复检查。
- `agent_failure_policy.py`：失败分类及恢复指导；`agent_interruption_policy.py`：确认、澄清、继续和阻止决策。
- `agent_run_store.py`：单次请求生命周期；`audit_store.py`：审计记录；`task_store.py`：任务记录。三者与 CAD 项目仓库不是同一份状态。

## 模型通信

- `model_request_gateway.py`：统一供应商请求入口及并发租约。
- `model_providers.py`：不同供应商协议适配；`deepseek_transport.py`：DeepSeek HTTP/流式传输、超时和资源释放。
- `user_model_config.py`：按用户保存模型设置；`request_context.py`：请求级用户上下文；`user_request_limits.py`：调用限制；`structured_usage.py`：结构化调用用量统计。

## 通用 Agent 计划

- `agent_plan_models.py`：计划、步骤、目标和成功条件契约。
- `agent_plan_orchestrator.py`：步骤依赖及状态迁移；`agent_plan_runtime.py`：把计划状态机接入实际聊天执行。
- `agent_plan_store.py`、`agent_plan_sqlite_store.py`：计划快照、版本与事件持久化。
- `agent_plan_recovery.py`：有界恢复决策；`agent_plan_evaluation.py`：离线事件链验收。

## CAD 需求与结构

- `cad_creation_intent.py`：创建意图和对象识别；`cad_coordinate_requirements.py`：坐标、单位和尺度信息。
- `cad_requirement_contract.py`：对象、参数作用域、有效事实和冲突；`cad_requirement_ledger.py`：原文、补参、来源与需求版本追踪。
- `cad_structure_contract.py`：组成、数量、部件关系的预检查与实际几何验证。
- `cad_construction_interpreter.py`：自然语言/规则/模型输出到构造计划，试执行并组装验收结果。
- `cad_construction.py`：严格构造协议与确定性执行，图元、曲线、阵列、预算和断言。
- `cad_parametric.py`：安全数学表达式和参数曲线采样；`cad_constraint_solver.py`：约束求解；`native_constraint_worker.py`：原生约束计算工作进程。
- `cad_sketch_graph.py`：结构图协议及候选转换。
- `cad_template_plan.py`：已有模板参数编译为统一计划；`cad_standard_templates.py`：标准模板几何及依据；`agent_skills.py`：模板识别、布局、评分与可行性辅助；`cad_reference_data/`：标准参考数据。

## CAD 验收与修复

- `cad_source_acceptance.py`：从原文独立核对具名原语。
- `cad_relation_acceptance.py`：具名对象关系；`cad_path_relation_acceptance.py`：路径连接与 S 形关系。
- `cad_repetition_acceptance.py`：重复、分支数量及关系；`cad_semantic_acceptance.py`：已支持的语义结构；`cad_stroke_acceptance.py`：笔画结构；`cad_projection_acceptance.py`：投影结构。
- `cad_object_constraints.py`：对象约束；`cad_visual_scoring.py`：外观评分辅助，评分不能替代独立验收。
- `cad_local_repair.py`：局部修复范围和补丁；`cad_generation_recovery.py`：生成失败恢复。
- `cad_plan_verifier.py`：执行结果适配为计划验证结果；`cad_plan_recovery.py`：调用 CAD 修复机制。

## CAD 修改

- `cad_edit_intent.py`：自然语言编辑意图；`cad_edit_contract.py`：CadEditCommand 数据契约。
- `cad_edit_interpreter.py`：模型辅助解释；`cad_target_resolver.py`：选区、实例、语义对象和图元目标解析。
- `cad_edit_session.py`：跨轮编辑命令状态；`cad_edit_chain.py`：多操作修改链；`cad_selected_operations.py`：选区操作。
- `incremental_cad.py`：增量解析及几何操作；`cad_edit_plan.py`：编辑计划；`cad_edit_preview.py`：前后预览。
- `cad_edit_gate.py`：编辑检查；`cad_assertions.py`：实际效果、非目标不变等机器断言；`cad_edit_relation_acceptance.py`：编辑后的关系验收。
- `cad_counterfactual_guard.py`：版本和保护范围检查；`cad_revision.py`：修订哈希、快照和版本验证。

## 候选、对象和存储

- `cad_project_candidates.py`：候选预期、几何验证、父版本选择和几何辅助；`cad_candidate_orchestrator.py`：准备、恢复和保存候选阶段编排。
- `cad_construction_commit.py`：计划试执行结果提交为项目候选。
- `cad_candidate_state.py`：候选是否具有通过验收证据的公共判断，当前尚需核查全部消费者是否接入。
- `creative_projects.py`：项目、候选、选择和状态持久化；`creative_workflow.py`：项目到规划、执行、恢复与报告的工作流。
- `logical_topology.py`：整体/部件/图元归属及连接验证；`geometry_catalog.py`：语义目录；`geometry_identity.py`：稳定身份；`geometry_diff.py`：版本几何差异；`spatial_partition.py`：空间分区。
- `database.py`：SQLite 持久化、迁移和维护，并承载部分历史/案例数据。

## 图纸文件

- `drawing_store.py`：图纸文件、几何读取和预览路径；`drawing_versions.py`：文件版本与回滚；`drawing_commands.py`：图纸命令。
- `cad_import.py`：DWG/DXF 转换导入；`image_drawing_import.py`：图片线稿矢量适配、标定和复核数据。

## 小车与施工

- `ros_adapter.py`：ROS2 节点、设备通信、规划与执行适配；`rosbridge_protocol.py`：桥接协议。
- `state.py`：后端共享设备/任务状态和虚拟演示状态；`telemetry_contract.py`：遥测数据契约。
- `discovery.py`：设备发现；`network_manager.py`：网络配置；`diagnostics.py`：设备链路及本地诊断。
- `mission_ledger.py`：施工任务台账；`mission_analysis.py`：任务分段分析；`mission_quality.py`：规划质量；`mission_reports.py`：报告。
- `construction_quality.py`：曲率、转角、接缝、喷头偏移与墨迹风险检查。
- `route_optimization_comparison.py`：路径顺序/方向对照；`trajectory_comparison.py`：计划与实际轨迹对比；`oscillation.py`：摆动检测。

## 主要调用关系

App 请求 → routers → agent_http_service → agent_service → 需求契约/创建或编辑解释 → 严格计划执行 → 实际几何验收 → 项目候选保存 → 响应适配与展示检查 → App 预览。

用户选择候选 → creative_workflow → ros_adapter 请求 ROS2 规划 → 人工确认执行 → 任务与设备状态 → 台账/施工报告。

注意：这是职责和主要路径说明，不表示每条分支都已经完全服从这些边界。目前仍存在候选状态消费者未全部统一、补参确认衔接及真实复杂语料失败等已知待修项。
